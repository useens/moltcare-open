## 技术实现

- **Rich库**: Python终端UI库
- **Live模式**: 实时刷新，无闪烁
- **Layout布局**: 响应式面板分割
- **Table组件**: 美观的数据表格
- **Panel组件**: 带标题的圆角面板

## 使用提示

1. 需要安装Rich库: `pip install rich`
2. 支持标准Linux/Mac终端
3. Windows终端需要支持ANSI颜色
4. 可以按Ctrl+C随时退出
5. 数据每2秒自动刷新
