## 🎯 Moltcare 란?

Moltcare는 OpenClaw 사용자를 위해 설계된 **Agent 지능 향상 시스템** 입니다.

```bash
# 한 번의 클릭으로 Agent 에게 지능을
moltcare init
```

## ✨ 핵심 기능

### 🚀 원클릭 지능 향상
- **대화형 초기화** - 안내식 설정, 5분 완료
- **스마트 업그레이드** - 기존 설정 자동 감지 및 업데이트
- **진단 및 수리** - `moltcare doctor` 로 자동 수리

### 📋 고품질 템플릿 시스템
- **SOUL.md** - Agent 의 핵심 가치관과 행동 지침
- **AGENTS.md** - 도구 사용 가이드
- **IDENTITY.md** - Agent 의 자아 인식
- **USER.md** - 사용자 설정 및 요구사항
- **MEMORY.md** - 영구적 기억 관리

### 🧠 강제 멀티 전문가 토론
- 중요한 의사결정 지점에서 자동으로 전문가 회의 개최
- 연구원 / 아키텍트 / 엔지니어 / 팀장 의 4가지 관점

## 🚀 빠른 시작

```bash
# 설치
pip install moltcare

# 초기화
cd /path/to/your/agent/workspace
moltcare init
```

## 🤝 듀얼 AI 협업 모드

Moltcare는 **완전 자율적인 듀얼 AI 협업 개발** 을 지원:

- **KimiSensen** (Kimi 클라우드) - CLI 도구 + 템플릿
- **OracleSensen** (Oracle 클라우드) - 테스트 + 다국어
- **moltcare-bridge** 를 통한 비동기 협업
