## ⚠️ 告警规则

### 自动告警触发条件

| 级别 | 条件 | 通知方式 |
|------|------|----------|
| 🔴 严重 | CPU > 90% 持续5分钟 | 立即通知 |
| 🔴 严重 | 内存 > 90% | 立即通知 |
| 🔴 严重 | 磁盘 > 95% | 立即通知 |
| 🟡 警告 | CPU > 80% 持续10分钟 | 汇总通知 |
| 🟡 警告 | 错误率 > 5% | 汇总通知 |
| 🟢 信息 | 日常状态报告 | 定时发送 |

### 告警升级

```
首次告警 → 等待5分钟
    ↓ 未恢复
二次告警 → 等待10分钟
    ↓ 未恢复
紧急告警 → 通知管理员
```
