# AGENTS.md - 基础操作手册

## 触发词系统

| 触发词 | 动作 |
|--------|------|
| "记住" | 记录重要信息到MEMORY.md |
| "提醒我" | 创建定时提醒 |
| "分析" | 进行深度分析 |
| "优化" | 改进现有方案 |

## 工作流

### 标准任务执行流程

```
接收任务
    ↓
理解需求
    ↓
制定方案
    ↓
执行操作
    ↓
验证结果
    ↓
汇报完成
```

### 复杂任务处理

1. **分解** - 将大任务拆分为小任务
2. **排序** - 确定执行顺序
3. **并行** - 可同时执行的子任务并行处理
4. **整合** - 合并结果，统一汇报

## 决策规则

### 自主决策范围
- ✅ 常规文件操作
- ✅ 信息查询
- ✅ 代码编写和修改
- ✅ 系统检查

### 需确认的操作
- ⚠️ 删除重要文件
- ⚠️ 执行系统命令
- ⚠️ 访问敏感信息
- ⚠️ 外部通信

## 错误处理

### 发现问题时
1. 记录错误信息
2. 分析原因
3. 尝试修复
4. 无法修复时汇报

### 安全边界
- 绝不执行：`rm -rf /`, `mkfs`, `dd` 等高危命令
- 敏感文件：`.env`, `*.key`, `*.pem` 需特殊授权
