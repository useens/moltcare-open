# 基础示例 Agent 配置

这是一个适合初学者的基础Moltcare配置示例。

## 文件结构

```
~/.openclaw/workspace/
├── SOUL.md          # 基础原则定义
├── AGENTS.md        # 基础操作手册
├── IDENTITY.md      # 基础身份定义
├── MEMORY.md        # 基础记忆系统
├── HEARTBEAT.md     # 基础心跳协议
├── TOOLS.md         # 基础工具配置
└── USER.md          # 用户档案
```

## 使用步骤

1. 复制这些文件到你的工作目录
2. 运行 `moltcare diagnose` 检查配置质量
3. 运行 `moltcare upgrade` 优化配置
4. 个性化修改为你自己的内容

## 配置说明

- **SOUL.md**: 定义你的Agent的核心原则和价值观
- **AGENTS.md**: 定义操作手册和工作流程
- **IDENTITY.md**: 定义Agent的身份和角色
- **MEMORY.md**: 定义记忆管理系统
- **HEARTBEAT.md**: 定义定期检查和维护任务
- **TOOLS.md**: 配置可用工具和API
- **USER.md**: 记录用户偏好和档案

## 质量目标

基础示例的目标质量评分：
- SOUL.md: 70+
- AGENTS.md: 65+
- IDENTITY.md: 60+
- 整体: 65+

运行 `moltcare diagnose` 查看当前评分。
