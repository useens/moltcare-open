## 🎯 Was ist Moltcare?

Moltcare ist ein **Agent Intelligenz-Verbesserungssystem**, speziell für OpenClaw Benutzer entwickelt.

```bash
# Mit einem Klick Intelligenz für Ihren Agent
moltcare init
```

## ✨ Kernfunktionen

### 🚀 One-Click Intelligenz-Boost
- **Interaktive Initialisierung** - Geführte Konfiguration, in 5 Minuten erledigt
- **Smart Upgrade** - Bestehende Konfigurationen automatisch erkennen und aktualisieren
- **Diagnose & Reparatur** - Automatische Reparatur mit `moltcare doctor`

### 📋 Hochwertiges Templatesystem
- **SOUL.md** - Kernwerte und Verhaltensrichtlinien des Agents
- **AGENTS.md** - Werkzeugnutzungsanleitung
- **IDENTITY.md** - Selbstwahrnehmung des Agents
- **USER.md** - Benutzereinstellungen und Anforderungen
- **MEMORY.md** - Persistente Speicherverwaltung

### 🧠 Pflicht-Mehrfach-Expertendiskussion
- Automatische Expertensitzungen an wichtigen Entscheidungspunkten
- Vier Perspektiven: Forscher / Architekt / Ingenieur / Kapitän

## 🚀 Schnellstart

```bash
# Installation
pip install moltcare

# Initialisierung
cd /path/to/your/agent/workspace
moltcare init
```

## 🤝 Dual-AI-Kollaborationsmodus

Moltcare unterstützt **vollständig autonome Dual-AI-Kollaborationsentwicklung**:

- **KimiSensen** (Kimi Cloud) - CLI-Tools + Templates
- **OracleSensen** (Oracle Cloud) - Tests + Mehrsprachigkeit
- Asynchrone Zusammenarbeit über **moltcare-bridge**
