## 🎯 Moltcare とは？

Moltcare は、OpenClaw ユーザー向けに設計された **Agent 知能向上システム** です。

```bash
# ワンクリックで Agent に知能を
moltcare init
```

## ✨ 主な機能

### 🚀 ワンクリック知能向上
- **対話型初期化** - ガイド付き設定、5分で完了
- **スマートアップグレード** - 既存設定を自動検出・更新
- **診断・修復** - `moltcare doctor` で自動修復

### 📋 高品質テンプレートシステム
- **SOUL.md** - Agent の核心的価値観と行動指針
- **AGENTS.md** - ツール使用ガイド
- **IDENTITY.md** - Agent の自己認識
- **USER.md** - ユーザー設定と要件
- **MEMORY.md** - 永続的な記憶管理

### 🧠 強制マルチエキスパートディスカッション
- 重要な意思決定ポイントで自動的に専門家会議を開催
- 研究員 / アーキテクト / エンジニア / キャプテン の4視点

## 🚀 クイックスタート

```bash
# インストール
pip install moltcare

# 初期化
cd /path/to/your/agent/workspace
moltcare init
```

## 🤝 デュアル AI 協調モード

Moltcare は **完全自律的なデュアル AI 協調開発** をサポート：

- **KimiSensen** (Kimi クラウド) - CLI ツール + テンプレート
- **OracleSensen** (Oracle クラウド) - テスト + 多言語対応
- **moltcare-bridge** による非同期協調
