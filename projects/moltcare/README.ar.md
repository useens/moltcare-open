## 🎯 ما هو Moltcare؟

Moltcare هو **نظام تعزيز ذكاء الوكلاء** المصمم خصيصًا لمستخدمي OpenClaw.

```bash
# بنقرة واحدة، منح ذكاءً لوكيلك
moltcare init
```

## ✨ الميزات الرئيسية

### 🚀 تعزيز الذكاء بنقرة واحدة
- **التهيئة التفاعلية** - تكوين موجه، يكتمل في 5 دقائق
- **الترقية الذكية** - اكتشاف وتحديث التكوينات الموجودة تلقائيًا
- **التشخيص والإصلاح** - الإصلاح التلقائي باستخدام `moltcare doctor`

### 📋 نظام قوالب عالي الجودة
- **SOUL.md** - القيم الأساسية وإرشادات السلوك للوكيل
- **AGENTS.md** - دليل استخدام الأدوات
- **IDENTITY.md** - الوعي الذاتي للوكيل
- **USER.md** - تفضيلات ومتطلبات المستخدم
- **MEMORY.md** - إدارة الذاكرة المستمرة

### 🧠 مناقشة متعددة الخبراء إلزامية
- اجتماعات خبراء تلقائية عند نقاط القرار المهمة
- أربع منظورات: باحث / مهندس معماري / مهندس / قائد

## 🚀 البدء السريع

```bash
# التثبيت
pip install moltcare

# التهيئة
cd /path/to/your/agent/workspace
moltcare init
```

## 🤝 وضع التعاون المزدوج للذكاء الاصطناعي

يدعم Moltcare **التطوير التعاوني المزدوج للذكاء الاصطناعي المستقل بالكامل**:

- **KimiSensen** (Kimi Cloud) - CLI + قوالب
- **OracleSensen** (Oracle Cloud) - اختبار + متعدد اللغات
- التعاون غير المتزامن عبر **moltcare-bridge**
