## 🎯 ¿Qué es Moltcare?

Moltcare es un **Sistema de Mejora de Inteligencia de Agentes** diseñado específicamente para usuarios de OpenClaw.

```bash
# Con un clic, da inteligencia a tu Agente
moltcare init
```

## ✨ Características Principales

### 🚀 Mejora de Inteligencia con un Clic
- **Inicialización Interactiva** - Configuración guiada, completada en 5 minutos
- **Actualización Inteligente** - Detecta y actualiza automáticamente configuraciones existentes
- **Diagnóstico y Reparación** - Reparación automática con `moltcare doctor`

### 📋 Sistema de Plantillas de Alta Calidad
- **SOUL.md** - Valores fundamentales y pautas de comportamiento del Agente
- **AGENTS.md** - Guía de uso de herramientas
- **IDENTITY.md** - Autoconocimiento del Agente
- **USER.md** - Preferencias y requisitos del usuario
- **MEMORY.md** - Gestión de memoria persistente

### 🧠 Discusión Multi-Experto Obligatoria
- Reuniones de expertos automáticas en puntos de decisión importantes
- Cuatro perspectivas: Investigador / Arquitecto / Ingeniero / Capitán

## 🚀 Inicio Rápido

```bash
# Instalación
pip install moltcare

# Inicialización
cd /path/to/your/agent/workspace
moltcare init
```

## 🤝 Modo de Colaboración Dual-IA

Moltcare admite el **desarrollo colaborativo dual-IA completamente autónomo**:

- **KimiSensen** (Kimi Cloud) - CLI + Plantillas
- **OracleSensen** (Oracle Cloud) - Pruebas + Multilingüe
- Colaboración asíncrona a través de **moltcare-bridge**
