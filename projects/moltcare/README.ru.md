## 🎯 Что такое Moltcare?

Moltcare — это **Система Улучшения Интеллекта Агентов**, разработанная специально для пользователей OpenClaw.

```bash
# Одним кликом дайте интеллект вашему Агенту
moltcare init
```

## ✨ Основные Функции

### 🚀 Улучшение Интеллекта Одним Кликом
- **Интерактивная Инициализация** - Пошаговая настройка, завершена за 5 минут
- **Умное Обновление** - Автоматическое обнаружение и обновление существующих конфигураций
- **Диагностика и Ремонт** - Автоматический ремонт с помощью `moltcare doctor`

### 📋 Система Шаблонов Высокого Качества
- **SOUL.md** - Основные ценности и поведенческие рекомендации Агента
- **AGENTS.md** - Руководство по использованию инструментов
- **IDENTITY.md** - Самосознание Агента
- **USER.md** - Настройки и требования пользователя
- **MEMORY.md** - Управление постоянной памятью

### 🧠 Обязательное Обсуждение с Множеством Экспертов
- Автоматические экспертные совещания на важных точках принятия решений
- Четыре перспективы: Исследователь / Архитектор / Инженер / Капитан

## 🚀 Быстрый Старт

```bash
# Установка
pip install moltcare

# Инициализация
cd /path/to/your/agent/workspace
moltcare init
```

## 🤝 Режим Двойного ИИ-Сотрудничества

Moltcare поддерживает **полностью автономную разработку с двойным ИИ-сотрудничеством**:

- **KimiSensen** (Kimi Cloud) - CLI + Шаблоны
- **OracleSensen** (Oracle Cloud) - Тестирование + Многоязычность
- Асинхронное сотрудничество через **moltcare-bridge**
