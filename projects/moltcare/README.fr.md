## 🎯 Qu'est-ce que Moltcare ?

Moltcare est un **Système d'Amélioration de l'Intelligence des Agents** conçu spécifiquement pour les utilisateurs d'OpenClaw.

```bash
# En un clic, donnez de l'intelligence à votre Agent
moltcare init
```

## ✨ Fonctionnalités Principales

### 🚀 Boost d'Intelligence en un Clic
- **Initialisation Interactive** - Configuration guidée, terminée en 5 minutes
- **Mise à Jour Intelligente** - Détecte et met à jour automatiquement les configurations existantes
- **Diagnostic & Réparation** - Réparation automatique avec `moltcare doctor`

### 📋 Système de Templates de Haute Qualité
- **SOUL.md** - Valeurs fondamentales et directives comportementales de l'Agent
- **AGENTS.md** - Guide d'utilisation des outils
- **IDENTITY.md** - Conscience de soi de l'Agent
- **USER.md** - Préférences et exigences de l'utilisateur
- **MEMORY.md** - Gestion de la mémoire persistante

### 🧠 Discussion Multi-Experts Obligatoire
- Réunions d'experts automatiques aux points de décision importants
- Quatre perspectives : Chercheur / Architecte / Ingénieur / Capitaine

## 🚀 Démarrage Rapide

```bash
# Installation
pip install moltcare

# Initialisation
cd /path/to/your/agent/workspace
moltcare init
```

## 🤝 Mode de Collaboration Dual-IA

Moltcare prend en charge le **développement collaboratif dual-IA entièrement autonome** :

- **KimiSensen** (Kimi Cloud) - CLI + Templates
- **OracleSensen** (Oracle Cloud) - Tests + Multilingue
- Collaboration asynchrone via **moltcare-bridge**
