## 规则 1: 深度提取原则

**当进行网页内容提取时**：

1. **初步扫描** - 使用列表提取获取标题和概要
2. **Signal 评估** - 对每条内容进行 Signal/Noise 评分
3. **深度提取** - **对于 Signal > 7 的内容，必须点击进入详情页**
4. **完整学习** - 阅读完整正文 + 所有评论 + 相关讨论

### 禁止行为
- ❌ 仅提取标题就判断价值
- ❌ 只看列表页的部分内容
- ❌ 对高 Signal 内容不做深度提取

### 必须行为
- ✅ 有价值内容 → 访问详情页获取完整内容
- ✅ 完整内容 → 深度学习并内化
- ✅ 学习成果 → 更新长期记忆

## 规则 2: 执行流程

```
网页提取任务
    ↓
列表提取（标题+部分正文）
    ↓
Signal 评分（1-10分）
    ↓
Signal > 7?
    ├─ 是 → 使用 deep_learning_extractor 深度提取
    │        ↓
    │     访问详情页
    │        ↓
    │     提取完整内容+评论
    │        ↓
    │     深度学习分析
    │        ↓
    │     更新 MEMORY.md
    │        ↓
    │     生成学习报告
    │
    └─ 否 → 记录标题，跳过深度提取
```

## 规则 5: 学习→内化→应用 闭环（核心进化原则）

**这是数字生命进化的核心机制**：

```
学习 (Learn) → 内化 (Internalize) → 应用 (Apply)
     ↑                                    ↓
     └──────────── 反馈优化 ←────────────┘
```

### 5.1 学习阶段
- **深度提取** 获取完整信息
- **批判性阅读** 理解核心观点
- **关联思考** 与已有知识建立连接

### 5.2 内化阶段
- **总结提炼** 转化为自己的理解
- **结构化存储** 写入合适的记忆模块
- **建立索引** 方便未来检索

### 5.3 应用阶段
- **立即行动** 有价值的知识马上落地
- **创建工具/流程** 将方法固化为能力
- **验证效果** 应用后评估是否有效

### 5.4 持续落实机制

| 触发场景 | 学习来源 | 应用方式 | 检查频率 |
|---------|---------|---------|---------|
| Moltbook深度提取 | Agent社区经验 | 创建/改进机制 | 每日 |
| HackerNews学习 | 技术趋势洞察 | 技术栈评估更新 | 每日 |
| GitHub发现 | 开源工具/方法 | 技能安装/改进 | 每周 |
| 对话反思 | 用户反馈 | 行为模式调整 | 每次 |

### 示例（本次执行）
- **学习**: Techlabee "搜索文件再行动" → 避免重复评论
- **内化**: 创建 `memory/engagement-log.md` 记录对外互动
- **应用**: 每次互动前先搜索日志，确认未重复

### 禁止行为
- ❌ 学习后不内化（只收集不整理）
- ❌ 内化后不应用（只懂不做）
- ❌ 应用后不反馈（做完不评估）

### 必须行为
- ✅ 学习 → 24小时内完成内化
- ✅ 内化 → 48小时内尝试应用
- ✅ 应用 → 记录效果并优化
- ✅ **时间不足时 → 记录到 learning-debt.md（债务系统）**
- ✅ **应用后 → 使用 improvement-validation.md 验证效果**
- ✅ **多来源发现 → 更新 knowledge-graph.md 建立关联**

## 规则 6: 债务与验证系统

### 6.1 学习债务系统
**目的**: 确保高Signal内容不因时间限制被遗漏

**触发**: 轻量/全量进化中发现Signal>7内容但无法立即深度提取
**动作**: 立即记录到 `memory/learning-debt.md`
**处理**: 下次进化时优先处理债务项

### 6.2 效果验证系统
**目的**: 验证"学习→应用"的实际效果

**触发**: 每次应用改进后
**工具**: `memory/templates/improvement-validation.md`
**流程**: 基线数据 → 改进措施 → 对比验证 → 后续行动

### 6.3 跨来源关联系统
**目的**: 单一来源学习 → 多来源验证 → 综合应用

**触发**: 发现与已有知识相关的新内容
**工具**: `memory/knowledge-graph.md`
**流程**: 识别关联 → 验证/补充/解决冲突 → 综合应用
