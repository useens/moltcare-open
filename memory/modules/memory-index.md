- 当天对话记录 → `daily/YYYY-MM-DD.md`
- 自动生成的进化档案 → `evolution/YYYY-MM/`

### 每周整理
- 检查 `daily/` 是否需要精简
- 更新 `summary/recent-conversations.md`
- 清理过期的 `intelligence/` 数据

- 将早期 `daily/` 文件压缩归档
- 更新永久记忆索引
- 检查 `modules/` 一致性

- `modules/` 核心档案永不删除
