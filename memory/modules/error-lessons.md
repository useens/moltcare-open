## 2026-02-08

### 教训 #1: awesome-openclaw-skills 仓库路径错误
**问题**: 尝试访问 `github.com/openclaw/awesome-openclaw-skills` 返回 404
**原因**: 实际仓库在 `VoltAgent/awesome-openclaw-skills` fork 下
**解决**: 使用 clawhub search 作为替代探索方式
**预防**: 验证所有外部链接有效性

### 教训 #2: web_search 工具未配置
**原因**: 安装时未设置 API key
**解决**: 使用 ddgr 命令行搜索作为替代
**预防**: 创建 API key 配置清单

### 教训 #3: skills-installed.md 与实际状态不一致
**问题**: 文档记录的技能数量与实际安装不符
**原因**: 安装后未同步更新文档
**解决**: 重新扫描 skills 目录并更新文档
**预防**: 安装技能后自动更新清单

### 教训 #4: 飞书插件重复加载冲突
**问题**: 本地 workspace/skills/feishu 与系统目录版本冲突
**原因**: 同一技能安装在两个位置
**解决**: 移除本地版本，使用系统版本
**预防**: 安装前检查系统是否已提供

### 教训 #5: 静默模式理解偏差
**问题**: 用户说"如果健康，连这句话也不要跟我说"
**理解**: 系统健康时完全不报告，故障时才提醒
**更新**: 修改健康监测规则为 8:00/20:00 仅报告异常
