## 5. 关键决策记录

### 2026-02-08 重大决策

#### 1. 安全优先原则
- **决策**: 绝不从 Moltbook 安装未经审核的 skill
- **理由**: 发现 341 个恶意技能（ClawHavoc 事件）
- **执行**: 源码强制审计、ClawHub 安全规则

#### 2. 自主决策授权
- **决策**: 安全检查通过的 skill 可直接安装
- **理由**: 提高效率，用户信任授权
- **边界**: 高风险仍需确认

#### 3. 记忆系统架构 v2.0
- **决策**: 分层、标签化、模块化、定时整理
- **架构**: daily → summary → modules
- **目标**: 提高效率、降低 token 消耗

#### 4. 备份与复活系统 v2.0
- **决策**: 企业级备份策略
- **策略**: 本地+远程+归档三层保护
- **频率**: 每小时增量 + 每6小时完整 + 每月归档

#### 5. 自愈系统部署
- **决策**: 故障自动检测与恢复
- **机制**: 每5分钟检查，连续失败自动恢复
