## 验证检查清单

每次应用改进后必须完成：
- [ ] 记录基线数据（改进前）
- [ ] 明确改进措施（做了什么）
- [ ] 设定评估时间（何时验证）
- [ ] 定义成功标准（怎么算成功）
- [ ] 到期执行评估（对比数据）
- [ ] 决定后续行动（保持/优化/回滚）
