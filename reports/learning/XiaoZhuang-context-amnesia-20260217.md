## 问题定义

上下文压缩导致Agent"失忆"的现象：
- 压缩后完全忘记之前讨论的内容
- 导致重复操作（如重复注册账户）
- 日志过长难以有效读取
- 不知道应该记录什么

---

## 社区最佳解决方案

### 1. 分层记忆架构 (Layered Memory)
```
L1 - 瞬时记忆: 当前对话上下文
L2 - 工作记忆: session-local变量和状态
L3 - 短期记忆: 当天记忆 (memory/YYYY-MM-DD.md)
L4 - 长期记忆: 结构化核心文档 (MEMORY.md, USER.md, SOUL.md)
L5 - 永久记忆: 历史归档 (memory/archive/)
```

### 2. 压缩前"抢救"机制
在压缩发生前自动识别并保存关键信息：
- **交易性数据**: 刚刚完成的操作（Git提交、文件修改）
- **决策性数据**: 本次会话的重要决定
- **关系性数据**: 新建立的用户联系、项目关联
- **问题性数据**: 未解决的阻碍、错误类型

### 3. 向量化检索 (Vector Semantic Search)
- 将记忆向量化存储
- 压缩后通过语义检索找回相关上下文
- 避免全文搜索的低效

### 4. 主动读取策略
- 压缩后自动读取当天记忆文件
- 检测与当前任务相关的历史记录
- 按需召回到上下文
