## 🔧 配置问题

### 1. **配置文件JSON语法错误**
```bash
$ cat /etc/v2ray/config.json | python3 -m json.tool
JSON invalid
```

⚠️ 虽然 `v2ray test` 报告"Configuration OK"，但JSON解析失败。这可能是:
- 文件包含JavaScript-style注释（V2Ray支持，但标准JSON解析器不认）
- 文件末尾有逗号或其他语法问题

**建议**: 清理注释，确保标准JSON格式

### 2. **include_* 注释未启用**
配置文件保留了大量注释掉的include指令，这些可以安全删除或明确启用。

### 3. **DNS服务器不可用**
`https+local://dns.google/dns-query` 持续超时，建议:
- 替换为本地DNS (如 `8.8.8.8`)
- 或使用更稳定的DoH服务

### 4. **无logrotate配置**
日志文件已达100MB级别，需要配置轮转。

## 📈 性能与优化建议

### 短期修复 (立即执行)

#### 1. **配置logrotate**
创建 `/etc/logrotate.d/v2ray`:
```bash
/var/log/v2ray/*.log {
    daily
    rotate 7
    compress
    delaycompress
    missingok
    notifempty
    create 640 root root
    sharedscripts
    postrotate
        systemctl reload v2ray 2>/dev/null || true
    endscript
}
```

#### 2. **修复DNS配置**
编辑 `/etc/v2ray/config.json`:
```json
"dns": {
  "servers": [
    "8.8.8.8",
    "1.1.1.1",
    "localhost"
  ]
}
```

#### 3. **清理配置文件**
移除无用注释，确保标准JSON格式。可使用以下脚本清理:
```bash
jq -c . /etc/v2ray/config.json > /etc/v2ray/config.json.clean && mv /etc/v2ray/config.json.clean /etc/v2ray/config.json
```

### 中期优化 (1周内)

#### 4. **明确配置模式**
决定使用:
- **客户端模式**: 仅outbound（当前模式）
- **服务端模式**: 提供inbound（如备份配置）

若只需作为客户端连接到远程服务器，应删除备份中的inbound配置，避免混淆。

#### 5. **监控连接数**
设置监控警报，异常高连接数可能表示被滥用。

#### 6. **审计访问控制**
当前客户端模式无需访问控制，但如果启用服务端模式，需设置:
- 强密码或UUID
- 限制连接IP
- 启用TLS
