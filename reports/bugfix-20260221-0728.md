### ✅ 已修复: Evolver超时

**问题描述**:
```
subprocess.TimeoutExpired: Command '['node', 'index.js', 'run']' timed out after 60 seconds
```

**发生频率**: 每次夜间进化 (23:00) 必现

**根因分析**:
1. 超时时间固定60秒，太短
2. 进化引擎spawn子Agent(`sessions_spawn`)需要更长执行时间
3. 17:57手动运行成功(~4秒) vs 23:00自动运行超时

**修复方案**:
- **文件**: `scripts/evolver-launcher.py`
- **变更**: 将超时时间从60秒改为300秒(5分钟)
- **新增**: 支持环境变量`EVOLVER_TIMEOUT`自定义超时时间

**代码变更**:
```python
# 修复前
result = subprocess.run(
    ["node", "index.js", "run"],
    cwd=EVOLVER_DIR,
    capture_output=True,
    text=True,
    timeout=60  # 固定60秒
)

# 修复后
timeout_seconds = int(os.environ.get("EVOLVER_TIMEOUT", "300"))
log(f"⏱️ 超时设置: {timeout_seconds}秒")
result = subprocess.run(
    ["node", "index.js", "run"],
    cwd=EVOLVER_DIR,
    capture_output=True,
    text=True,
    timeout=timeout_seconds  # 可配置，默认300秒
)
```

### ⚠️ 诊断完成: Git推送失败

**问题描述**:
```
⚠️ 推送失败（可能远程不可达）
fatal: could not read Password for 'https://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@github.com': No such device or address
```

**发生频率**: 每次健康检查后推送 (每30分钟)

**根本原因**:
- ✅ 已定位: **GitHub Token已过期** (HTTP 401响应)
- ⚠️ `.git/config`中URL缺少Token配置
- ⚠️ 缓存的Token与实际配置不一致

**诊断过程**:
1. 发现`.git/config`中URL: `https://github.com/useens/linlin-backup.git` (无Token)
2. `git remote get-url`显示: `https://ghp_...@github.com/...` (有Token，但可能是临时配置)
3. 使用curl测试Token有效性: `401 Unauthorized`
4. 确认Token已过期

**尝试的修复方案**:
| 方案 | 结果 | 说明 |
|------|------|------|
| 更新`.git/config`添加Token | ❌ 仍失败 | Token本身无效 |
| 配置`.git-credentials`文件 | ❌ 仍失败 | Token无权限 |
| 改进错误提示信息 | ✅ 完成 | 帮助后续诊断 |

**改进的监控脚本**:
- **文件**: `scripts/unified-monitor.py`
- **变更**: 添加详细的错误分类和提示

**新增错误提示**:
```python
if "could not read Password" in push_result.stderr:
    logger.error(f"    ❌ 原因: Git认证失败 - Token可能已过期或未配置")
    logger.error(f"       请在 GitHub Settings > Developer settings > Personal access tokens 重新生成Token")
elif "401" in push_result.stderr or "403" in push_result.stderr:
    logger.error(f"    ❌ 原因: Token无效或无权限")
else:
    logger.error(f"    ❌ 错误信息: {push_result.stderr[:200]}")
```

**需要用户手动操作**:
1. 前往 GitHub Settings → Developer settings → Personal access tokens
2. 复选合适的权限: `repo`, `workflow`
3. 生成新的Token (有效期建议设置为无限或1年)
4. 更新以下配置:
   - `.git/config`中的remote URL
   - `~/.git-credentials`文件（如已配置）

**修复验证**: 需要用户提供新Token后验证
