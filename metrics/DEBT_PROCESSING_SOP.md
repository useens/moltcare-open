# 债务处理标准操作流程 (SOP)

## 处理前检查清单
- [ ] Signal评分确认
- [ ] 截止时间确认
- [ ] 无重复处理

## 处理中标准
1. **阅读原始内容** - 完整理解主题
2. **提取核心观点** - 用自己的话总结
3. **关联系统改进** - 必须关联具体改进点
4. **撰写学习笔记** - 保存到 `memory/debt-learning/DEBT-XXX.md`

## 处理后强制验证
运行验证命令：
```bash
python3 metrics/validate_debt.py DEBT-XXX
```

### 验证标准
| 检查项 | 通过标准 | 权重 |
|--------|----------|------|
| 笔记文件存在 | `memory/debt-learning/DEBT-XXX.md` 存在 | 必需 |
| 内容完整性 | 包含核心观点+个人洞察+行动项 | 30% |
| 关联改进 | 有具体系统改进关联 | 40% |
| 可执行性 | 行动项可验证 | 30% |

## 完成标记规则
- 验证通过 → 标记 `✅ 已完成`
- 验证不通过 → 标记 `🔄 待完善`，回到处理中

## 严禁行为
- ❌ 未验证就标记完成
- ❌ 笔记只有链接没有内容
- ❌ 没有关联系统改进
