## 🤔 Why MoltCare?

### The Problem: Most AI Agents Are Too Passive

Your AI assistant probably does this:
- Tries once, fails, gives up
- Asks you for info it could find itself  
- Says "I can't" instead of "Let me try another way"
- Completes tasks superficially without checking edge cases

**MoltCare fixes this with the PUA (Proactive Unstoppable Agent) Framework.**

### What Makes MoltCare Different?

| Feature | Other Frameworks | MoltCare |
|---------|------------------|----------|
| **Size** | 1000+ lines | **~5KB total** |
| **Approach** | Comprehensive | **High-signal density** |
| **Problem-solving** | Single attempt | **Multi-level escalation (L1-L4)** |
| **User frustration** | Agent gives up | **Agent fights harder** |

### 🔥 PUA Framework (v2.3.5)

**P**roactive **U**nstoppable **A**gent — When tasks fail, your agent fights harder instead of giving up.

#### Three Iron Laws

| Law | Description | Anti-Pattern |
|-----|-------------|--------------|
| **Exhaust Everything** | Never say "can't solve" before trying all options | Give up after 1-2 attempts |
| **Act First, Ask Later** | Use tools to investigate before asking user | Ask "please confirm X" with empty hands |
| **Take Ownership** | End-to-end delivery, owner mindset | Stop at "just enough" |

#### Pressure Escalation Levels

| Level | Trigger | Forced Action |
|-------|---------|---------------|
| **L1** | "Try again" / "Another way" | Switch to fundamentally different approach |
| **L2** | "Why still not working" / 2 failures | Search + read source + list 3 hypotheses |
| **L3** | "You're not capable" / 3+ failures | Complete 7-item checklist + full investigation |
| **L4** | "I can't solve this" / 5+ failures | Panic mode: minimal PoC + isolated env + different stack |

#### 7-Item Checklist (L3+ Mandatory)

When stuck, agents must complete:
- [ ] Read failure signal character by character
- [ ] Actively search for core issue
- [ ] Read raw materials (50 lines source/docs)
- [ ] Verify all assumptions
- [ ] Try inverting assumptions
- [ ] Isolate and reproduce at minimum scope
- [ ] Switch tools/methods/angles for verification

### Method 1: One-Line Install (Recommended)

```bash
curl -fsSL https://raw.githubusercontent.com/useens/moltcare-open/master/install.sh | bash
```

### Method 2: Manual Installation

```bash
# Clone repository
git clone https://github.com/useens/moltcare-open.git

# Copy core templates to OpenClaw workspace
cp moltcare-open/templates/core/*.md ~/.openclaw/workspace/
cp moltcare-open/templates/system/*.md ~/.openclaw/workspace/
cp -r moltcare-open/templates/memory ~/.openclaw/workspace/
```
