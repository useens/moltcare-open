## 4. 通过标准

### 4.1 总体标准

| 标准 | 要求 | 权重 |
|------|------|------|
| 功能完整性 | 所有核心功能可用 | 40% |
| 搜索准确性 | 返回相关结果 | 30% |
| 性能达标 | 满足性能指标 | 20% |
| 稳定性 | 无崩溃或严重错误 | 10% |

### 4.2 详细通过标准

#### 必须通过 (Critical)
- [ ] 索引功能正常工作
- [ ] 至少3种搜索类型可用
- [ ] 状态检查返回有效数据
- [ ] 搜索延迟 < 2000ms
- [ ] 无JavaScript运行时错误

#### 应该通过 (Major)
- [ ] 全部5种搜索类型可用
- [ ] 搜索结果相似度 ≥ 0.3
- [ ] 智能回退机制工作
- [ ] 并发搜索完成时间 < 5000ms

#### 建议通过 (Minor)
- [ ] 内存增长 < 100MB
- [ ] 缓存效果明显
- [ ] 帮助文档完整

### 4.3 评分标准

```
通过率 = 通过测试数 / 总测试数 × 100%

等级划分:
- A级 (90-100%): 优秀，系统完全可用
- B级 (80-89%): 良好，主要功能正常
- C级 (70-79%): 合格，存在问题但可用
- D级 (60-69%): 不合格，需要修复
- F级 (<60%): 严重问题，不可用
```

**最低通过标准**: 通过率 ≥ 80% (B级)

### 5.3 故障排除

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 模型加载失败 | 首次运行，需下载模型 | 等待下载完成（约80MB） |
| 内存不足 | 系统内存不够 | 增加swap或减少并发 |
| 索引失败 | 权限问题 | 检查目录权限 |
| 搜索无结果 | 阈值过高 | 调整相似度阈值 |
