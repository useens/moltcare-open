## 测试场景详解

### 场景 1: 批量索引测试

**目标**: 验证系统能够正确索引 Markdown 文件

**执行内容**:
1. 检查现有索引状态
2. 执行向量同步
3. 验证索引结果

**预期结果**:
- 状态检查返回有效JSON
- 同步命令执行成功
- 向量数据库更新正确

### 场景 2: 五种搜索类型

| # | 搜索类型 | 示例查询 | 验证点 |
|---|----------|----------|--------|
| 1 | 精确关键词 | "memory" | 返回包含关键词的结果 |
| 2 | 语义搜索 | "search engine" | 理解概念返回相关结果 |
| 3 | 短语搜索 | "vector memory" | 支持多词短语匹配 |
| 4 | 模糊概念 | "how to optimize" | 理解意图返回相关内容 |
| 5 | 特殊场景 | "smart_memory.js" | 支持文件名等特殊查询 |

### 场景 3: 关联功能验证

| 功能 | 描述 | 通过标准 |
|------|------|----------|
| 状态检查 | `--status` 命令 | 返回包含model、chunks、status的JSON |
| 智能回退 | 向量失败时自动回退 | 搜索始终返回结果 |
| 结果限制 | `maxResults` 参数 | 结果数量不超过设定值 |
| 格式验证 | 返回JSON结构 | 包含query、results等字段 |
| CLI帮助 | 帮助信息 | 显示使用说明 |

### 场景 4: 性能指标

| 指标 | 目标值 | 测试方法 |
|------|--------|----------|
| 搜索延迟 | < 1000ms | 10次搜索取平均 |
| 并发搜索 | < 5000ms (5个并行) | 同时启动5个搜索 |
| 资源使用 | 磁盘 < 90% | 检查磁盘空间 |

## 通过标准

### 评分规则

```
通过率 = (通过数 / 总测试数) × 100%

等级:
- A级 (90-100%): 优秀
- B级 (80-89%): 良好 ✓ 最低通过
- C级 (60-79%): 合格
- D级 (<60%): 不合格
```

### 强制要求

- [x] 无严重错误 (JavaScript 崩溃)
- [x] 核心功能可用 (搜索、状态检查)
- [x] 通过率 ≥ 80%
