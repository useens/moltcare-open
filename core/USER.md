## 💡 使用提示

### 如何最大化利用本文件

1. **初次使用**: 花 10 分钟填写基础信息
2. **日常交互**: 说"我偏好..."让 Agent 自动更新
3. **定期回顾**: 每月检查一次，更新技能和偏好
4. **项目切换**: 更新"当前项目"部分的约束条件

### OpenClaw 快速更新模板
```markdown
今天我想更新：
- [ ] 技术栈（学会了新技能）→ Agent 将更新本文件和 memory/preferences.md
- [ ] 沟通偏好（觉得之前的不好）→ Agent 将更新本文件
- [ ] 工作模式（换了新工作/项目）→ Agent 将更新约束条件
- [ ] 约束条件（新项目有特殊要求）→ Agent 将更新 memory/constraints.md
```

### 配合 memory_search 使用
- Agent 使用 `memory_search("用户偏好")` 检索本文件
- 使用 `memory_search("今日任务")` 检索每日日志
- 使用 `memory_search("学习债务")` 检索待学习内容
