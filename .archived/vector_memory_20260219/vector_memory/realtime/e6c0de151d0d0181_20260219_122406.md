## 概述

Google官方开发的MCP服务器，让AI编码代理控制Chrome浏览器进行：
- 性能分析和优化建议
- 网络请求调试
- 浏览器自动化（点击、填写、截图）
- JavaScript执行

---

## 核心功能

### 1. 输入自动化 (8个工具)
- `click` / `hover` / `drag` - 鼠标操作
- `fill` / `fill_form` - 表单填写
- `press_key` - 键盘输入
- `upload_file` / `handle_dialog` - 文件上传和弹窗

### 2. 导航自动化 (6个工具)
- `navigate_page` - 页面跳转
- `new_page` / `close_page` - 标签管理
- `list_pages` / `select_page` - 多标签切换
- `wait_for` - 等待元素/超时

### 3. 性能分析 (3个工具)
- `performance_start_trace` / `performance_stop_trace` - 录制性能追踪
- `performance_analyze_insight` - 提取可执行的性能优化建议
- 使用Chrome DevTools原生能力
- 可发送URL到Google CrUX API获取真实用户体验数据

### 4. 网络调试 (2个工具)
- `list_network_requests` - 列出所有网络请求
- `get_network_request` - 获取特定请求详情

### 5. 调试工具 (5个工具)
- `take_screenshot` / `take_snapshot` - 截图和DOM快照
- `list_console_messages` / `get_console_message` - 控制台日志
- `evaluate_script` - 执行JavaScript

## 配置方式

### 标准安装
```json
{
  "mcpServers": {
    "chrome-devtools": {
      "command": "npx",
      "args": ["-y", "chrome-devtools-mcp@latest"]
    }
  }
}
```

### 支持的客户端
- ✅ Claude Code / Claude Desktop
- ✅ Gemini CLI / Gemini Code Assist
- ✅ GitHub Copilot / VS Code
- ✅ Cursor
- ✅ Cline, Codex, Windsurf, Warp等

### 高级配置
```bash
# 连接现有Chrome实例
--browser-url=http://127.0.0.1:9222

# 无头模式
--headless=true

# 隔离模式（临时用户数据目录）
--isolated=true

# 禁用性能CrUX数据
--no-performance-crux

# 禁用使用统计
--no-usage-statistics
```
