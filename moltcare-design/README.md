## ✨ 核心功能

| 功能 | 命令 | 描述 |
|------|------|------|
| 🚀 初始化 | `moltcare init` | 一键创建高质量核心文件 |
| ⚡ 增强 | `moltcare enhance` | 智能升级到最佳实践 |
| 🔍 诊断 | `moltcare doctor` | 全面检查核心文件问题 |
| 🔄 升级 | `moltcare upgrade` | 更新到最新模板版本 |
| 🌍 多语言 | `moltcare lang` | 支持9种语言切换 |
| 🧠 多专家 | `moltcare discuss` | 强制触发多专家讨论 |

## 🚀 快速开始

### 安装

```bash
npm install -g moltcare
```

### 初始化你的 Agent

```bash
moltcare init MyAgent
```

这将创建:
- `SOUL.md` - Agent灵魂与原则
- `AGENTS.md` - 操作手册
- `MEMORY.md` - 记忆系统
- `IDENTITY.md` - 身份档案
- `HEARTBEAT.md` - 心跳检查

### 诊断当前配置

```bash
moltcare doctor
```

### 切换到英文

```bash
moltcare lang en
```

## 🧠 强制多专家讨论

**Moltcare 的核心特色** — 在关键决策时强制触发多专家讨论。

### 自动触发条件

- PR标题包含 `[ARCH]`, `[CORE]`, `[SECURITY]`, `[BREAKING]`
- 修改架构核心文件
- 版本 major/minor 升级

### 手动触发

```bash
moltcare discuss "架构设计决策"
```
