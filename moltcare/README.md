## 🎯 项目愿景

Moltcare 是一个为 OpenClaw Agent 设计的智能提升工具。许多刚安装的 Agent 核心文件写得差、容易出错，Moltcare 提供一键式解决方案，让任何 Agent 都能快速获得专业级的核心配置。

## ✨ 核心特性

- 🚀 **一键智能提升** - 自动优化 SOUL.md、AGENTS.md、IDENTITY.md 等核心文件
- 🧠 **强制多专家讨论** - 重要开发阶段自动触发深度多专家讨论
- 📦 **开箱即用** - 无需复杂配置，安装即可使用
- 🌍 **多语言支持** - 支持 9 种语言（开发中）
- 🔒 **安全优先** - 所有操作都有安全检查和保护

## 🚀 快速开始

```bash
# 安装 Moltcare
npm install -g moltcare

# 一键提升你的 Agent
moltcare enhance

# 生成专业级核心文件
moltcare init --template professional
```
