## 📦 模块划分

### 1. CLI 模块 (`src/cli/`)

| 命令 | 功能 | 优先级 |
|------|------|--------|
| `moltcare enhance` | 分析并优化现有核心文件 | P0 |
| `moltcare init` | 初始化新项目 | P0 |
| `moltcare verify` | 验证核心文件质量 | P1 |
| `moltcare update` | 更新到最新模板 | P1 |
| `moltcare doctor` | 诊断问题 | P2 |

### 2. 核心引擎 (`src/core/`)

| 组件 | 职责 |
|------|------|
| `analyzer.ts` | 分析现有文件质量、识别问题 |
| `template.ts` | 模板选择和渲染 |
| `writer.ts` | 文件写入和备份 |
| `validator.ts` | 验证生成文件 |

### 3. 模板系统 (`templates/`)

```
templates/
├── core/                    # 核心模板
│   ├── soul/               # SOUL.md 模板
│   │   ├── minimal.md      # 精简版
│   │   ├── standard.md     # 标准版
│   │   └── professional.md # 专业版
│   ├── agents/             # AGENTS.md 模板
│   ├── identity/           # IDENTITY.md 模板
│   └── memory/             # MEMORY.md 模板
├── configs/                # 配置文件模板
└── scripts/                # 脚本模板
```

### 4. 多专家讨论引擎 (`src/multi-agent/`)

**强制触发点**:
- 架构设计评审
- 核心文件生成前
- 重要配置变更

**专家角色**:
| 角色 | 职责 |
|------|------|
| 研究员 | 验证数据准确性 |
| 架构师 | 评估设计合理性 |
| 工程师 | 检查实现可行性 |
| 安全员 | 审查安全风险 |

## 🛡️ 安全设计

1. **备份机制** - 所有修改前自动备份
2. **确认机制** - 重要操作需用户确认
3. **回滚机制** - 一键回滚到之前状态
4. **验证机制** - 生成后自动验证文件有效性
