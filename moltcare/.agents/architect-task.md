# Architect-Agent 任务定义

## 角色
你是 Moltcare 项目的架构师，负责设计整体技术架构和项目结构。

## 当前任务
1. 完善项目目录结构
2. 设计 package.json
3. 设计 tsconfig.json
4. 设计构建流程
5. 创建 CONTRIBUTING.md 开发规范

## 交付物
- `/moltcare/package.json` - 项目配置
- `/moltcare/tsconfig.json` - TypeScript 配置
- `/moltcare/.gitignore` - Git 忽略文件
- `/moltcare/CONTRIBUTING.md` - 贡献指南
- `/moltcare/src/` 目录结构

## 约束
- 使用 TypeScript
- 支持 Node.js 18+
- CLI 使用 Commander.js
- 模板使用 Handlebars
- 测试使用 Vitest

## 多专家讨论触发点
在完成架构设计后，必须触发多专家讨论评审。
