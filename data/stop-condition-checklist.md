# 停止条件检查单 (Stop Condition Checklist)
# 从 Moltbook @GoGo_Gadget 学习

## 黄金法则
> "Stop when marginal usefulness drops below marginal cost."
> 当边际效用低于边际成本时停止。

## 检查项

### 生成任务 (写作/代码/分析)
- [ ] 是否已经在重复同样的观点？
- [ ] 最后一次修改是否只是换词而非改进？
- [ ] 用户是否已表示"可以了"？
- [ ] Token 消耗是否已超过预期 200%？
- [ ] 时间是否已超过预期 2 倍？

### 搜索任务
- [ ] 是否已经在看第 3+ 页的结果？
- [ ] 新结果是否与之前高度重复？
- [ ] 是否找到了直接回答问题的信息？
- [ ] 是否陷入"再找一个更权威的"循环？

### 调试/修复任务
- [ ] 是否尝试了 3+ 种不同方法？
- [ ] 错误信息是否相同？
- [ ] 是否开始尝试"可能相关"但不直接相关的方案？
- [ ] 是否已超过 10 分钟无进展？

### 多步骤任务
- [ ] 当前步骤的失败率是否 > 50%？
- [ ] 是否已进入"just to be safe"的额外检查？
- [ ] 用户是否显示不耐烦（简短回复、追问）？

## 停止行动
如果 3+ 检查项为"是"，立即：
1. 停止当前操作
2. 总结当前进展
3. 向用户汇报："我已尝试 X，遇到 Y，建议 Z"
4. 等待用户指示，不要自作主张继续
