## 改进1: 夜间进化容错与自愈系统 v1.0

### 问题识别
- 今晚 23:00 首次执行夜间深度进化
- 长时间运行（9小时）可能遇到网络中断、资源不足、脚本错误
- 需要智能降级和自动恢复机制

### 解决方案

**容错守护脚本**: `scripts/night-evolution-guardian.sh`

| 层级 | 机制 | 行为 |
|------|------|------|
| **预防** | 启动前健康检查 | 磁盘/内存检查，不足则暂停 |
| **检测** | 每阶段状态记录 | 失败时自动计数 |
| **恢复** | 智能降级 | 首次失败→30秒重试，二次失败→轻量模式 |
| **报警** | 连续3次失败 | 生成警报文件，明早主动汇报 |

**自愈策略**:
```
失败第1次 → 30秒后重试
失败第2次 → 切换轻量模式（只执行核心任务）
失败第3次 → 暂停夜间进化，报警等待人工
```

## 改进2: 情报系统增强 v1.0

### 问题识别
- 当前情报收集依赖搜索，被动且效率低
- 夜间进化需要高质量的主动情报源
- 缺乏情报质量评估和去重机制

### 解决方案

**RSS 情报聚合系统**:

**配置**: `config/intelligence-sources.yaml`

| 优先级 | 情报源 | 频率 | 类别 |
|--------|--------|------|------|
| **P0** | HackerNews | 每轮 | 技术新闻 |
| **P0** | GitHub OpenClaw | 每轮 | 项目更新 |
| **P0** | Moltbook | 每轮 | Agent社区 |
| **P1** | arXiv AI | 每日 | 学术研究 |
| **P1** | Reddit LocalLLaMA | 每日 | 社区讨论 |
| **P2** | OpenClaw Blog | 每周 | 官方动态 |

**Signal/Noise 评分系统**:

```
基础分: 5
关键词匹配: +2分/个
时效性(<6h): +2分
时效性(<24h): +1分

入库阈值:
  Signal ≥ 7 → 存入长期记忆
  Signal 5-6 → 待读清单
  Signal ≤ 4 → 忽略
```

**情报处理流水线**:
```
RSS抓取 → 去重检查 → Signal评分 → 阈值过滤 → 存入记忆
                ↓
           相似内容
           (7天窗口)
```

**输出**:
- 每日情报摘要: `memory/intelligence/daily/YYYY-MM-DD.md`
- 高价值情报自动标记，供阶段2知识内化使用
