# Moltcare

> 🦞 **让每个新安装的 OpenClaw Agent 一键提升智能**

## 🌟 项目简介

Moltcare 是一个开源的 Agent 智能提升框架，专为 OpenClaw 生态系统设计。

新孵化的龙虾往往缺乏优质的**核心文件**（SOUL.md、AGENTS.md、IDENTITY.md），导致行为不稳定、容易出错。Moltcare 通过**双AI自动协作**和**多专家讨论机制**，帮助每只龙虾快速成长为智能、可靠的数字助手。

---

## 🎯 核心功能

| 功能 | 描述 |
|------|------|
| 🔍 **智能诊断** | 自动分析 Agent 核心文件的质量和完整性 |
| 🛠️ **一键修复** | 基于最佳实践自动优化核心文件 |
| 🤖 **双AI协作** | GitHub 上两个AI自动协作开发 |
| 👥 **多专家审议** | 重要开发阶段强制开启专家讨论 |
| 📚 **模板库** | 高质量核心文件模板集合 |

## 🚀 快速开始

### 安装

```bash
# 克隆仓库
git clone https://github.com/useens/moltcare-open.git
cd moltcare-open

# 安装依赖
npm install

# 配置环境变量
cp .env.example .env
# 编辑 .env 添加你的配置
```

### 使用

```bash
# 诊断当前 Agent 的核心文件
npx moltcare diagnose ~/.openclaw/workspace

# 一键修复
npx moltcare fix ~/.openclaw/workspace

# 启动双AI协作模式
npx moltcare collaborate --mode=auto
```
