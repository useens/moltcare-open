# 森森智能水平升级守护服务规格

> **文档类型**: systemd Service Specification  
> **服务名称**: `sensen-self-upgrade.service`  
> **版本**: v1.1  
> **制定日期**: 2026-02-16  
> **Thinking模式**: 支持L2(medium)和L3(high)动态切换

---

## 一、服务概述

### 1.1 服务目的

自动执行森森智能水平的持续评估、弱项分析、升级执行和效果验证，实现真正的**绝对持续迭代**。

### 1.2 服务职责

| 阶段 | 职责 | 输出 |
|------|------|------|
| 评估 | 运行智能水平评估脚本 | 评分报告 |
| 分析 | 识别最弱维度 | 弱项分析 |
| 升级 | 执行针对性改进 | 升级日志 |
| 验证 | 验证升级效果 | 验证报告 |

### 1.3 服务架构


## 二、服务配置

### 2.1 systemd Unit File

**文件路径**: `/etc/systemd/system/sensen-self-upgrade.service`

```ini
[Unit]
Description=Sensen Self-Upgrade Daemon
Documentation=/root/.openclaw/workspace/memory/self-upgrade/design/systemd-service-spec.md
After=network.target
Wants=network.target

[Service]
Type=simple
User=root
Group=root
WorkingDirectory=/root/.openclaw/workspace

# 环境变量
Environment="PYTHONPATH=/root/.openclaw/workspace"
Environment="LOG_LEVEL=INFO"
Environment="UPGRADE_MODE=production"
Environment="THINKING_MODE=adaptive"  # low/medium/high/adaptive
Environment="L3_TRIGGER_SIGNAL=9"     # Signal阈值触发L3
Environment="DEFAULT_THINKING=medium" # 默认thinking模式

# 主执行命令
ExecStart=/usr/bin/python3 /root/.openclaw/workspace/scripts/self-upgrade-daemon.py

# 重启策略
Restart=always
RestartSec=60
StartLimitInterval=300
StartLimitBurst=3

# 资源限制
# 基于绝对解除限制原则，使用充足资源
MemoryMax=8G
MemorySwapMax=2G
CPUQuota=200%
TasksMax=100

# 日志配置
StandardOutput=journal
StandardError=journal
SyslogIdentifier=sensen-self-upgrade

# 安全设置
NoNewPrivileges=false
ProtectSystem=no
ProtectHome=no
ReadWritePaths=/root/.openclaw/workspace

[Install]
WantedBy=multi-user.target
```

### 2.2 定时触发配置

**文件路径**: `/etc/systemd/system/sensen-self-upgrade.timer`

```ini
[Unit]
Description=Sensen Self-Upgrade Timer
Documentation=/root/.openclaw/workspace/memory/self-upgrade/design/systemd-service-spec.md

[Timer]
# 每日02:00执行完整升级周期
OnCalendar=02:00:00

# 每6小时执行快速检查
OnCalendar=*-*-* 00,06,12,18:00:00

# 启动后1分钟首次执行
OnBootSec=1min

# 持久化（错过的时间点补上）
Persistent=true

[Install]
WantedBy=timers.target
```

## 三、核心脚本规格

### 3.1 主守护进程脚本

**文件路径**: `scripts/self-upgrade-daemon.py`

```python
#!/usr/bin/env python3
"""
森森智能水平升级守护进程
实现绝对持续迭代原则
"""

import os
import sys
import time
import logging
import subprocess
from datetime import datetime
from pathlib import Path

# 配置
WORKSPACE = Path("/root/.openclaw/workspace")
LOG_FILE = WORKSPACE / "logs" / "self-upgrade-daemon.log"
PID_FILE = WORKSPACE / "data" / "self-upgrade.pid"

# 升级周期配置
UPGRADE_INTERVAL = 86400  # 24小时
QUICK_CHECK_INTERVAL = 21600  # 6小时

# 脚本路径
SCRIPTS = {
    'assess': WORKSPACE / 'scripts' / 'intelligence-assessment.py',
    'analyze': WORKSPACE / 'scripts' / 'weakness-analyzer.py',
    'upgrade': WORKSPACE / 'scripts' / 'intelligence-upgrader.py',
    'verify': WORKSPACE / 'scripts' / 'intelligence-verifier.py',
}

# 日志配置
logging.basicConfig(
    level=logging.INFO,
    format='[%(asctime)s] [%(levelname)s] %(message)s',
    handlers=[
        logging.FileHandler(LOG_FILE),
        logging.StreamHandler(sys.stdout)
    ]
)
logger = logging.getLogger('self-upgrade')


class SelfUpgradeDaemon:
    """自我升级守护进程 - 支持Thinking模式切换"""
    
    THINKING_MODES = {
        'quick_assess': 'medium',    # L2: 快速评估
        'deep_assess': 'high',       # L3: 深度评估
        'upgrade_execute': 'high',   # L3: 升级执行
        'verify': 'medium',          # L2: 验证检查
    }
    
    def run_full_upgrade_cycle(self):
        """执行完整升级周期 - 根据任务类型设置Thinking模式"""
        logger.info("=" * 60)
        logger.info("开始完整升级周期")
        logger.info("=" * 60)
        
        results = {}
        
        # 阶段1: 评估 (L3 - 深度评估)
        self.set_thinking_mode('high')
        results['assess'] = self.run_phase('assess', '智能水平评估')
        
        # 阶段2: 分析 (L3 - 架构级分析)
        self.set_thinking_mode('high')
        results['analyze'] = self.run_phase('analyze', '弱项分析')
        
        # 阶段3: 升级 (L3 - 复杂执行)
        if results['assess'] and results['analyze']:
            self.set_thinking_mode('high')
            results['upgrade'] = self.run_phase('upgrade', '执行升级')
        else:
            logger.warning("评估或分析失败，跳过升级阶段")
            results['upgrade'] = False
        
        # 阶段4: 验证 (L2 - 效果确认)
        if results['upgrade']:
            self.set_thinking_mode('medium')
            results['verify'] = self.run_phase('verify', '效果验证')
        else:
            logger.warning("升级阶段失败，跳过验证阶段")
            results['verify'] = False
        
        # 汇总
        self.summarize_cycle(results)
    
    def run_quick_check(self):
        """执行快速检查 - L2级别"""
        logger.info("执行快速状态检查... [Thinking: medium]")
        self.set_thinking_mode('medium')
        # 快速检查逻辑...
        
    def set_thinking_mode(self, mode):
        """设置当前thinking模式"""
        os.environ['CURRENT_THINKING_MODE'] = mode
        logger.info(f"Thinking模式切换: {mode}")


def main():
    daemon = SelfUpgradeDaemon()
    daemon.run()


if __name__ == '__main__':
    main()
```

## 四、监控与告警

### 4.1 健康检查端点

```bash
# 服务状态检查
systemctl is-active sensen-self-upgrade.service
```

### 4.2 告警规则

**文件**: `config/self-upgrade-alerts.yaml`

```yaml
alerts:
  - name: upgrade_failed
    condition: "last_upgrade_status != 'success'"
    severity: critical
    action: notify_user
    
  - name: low_score
    condition: "overall_score < 70"
    severity: warning
    action: log_and_notify
    
  - name: script_missing
    condition: "required_script_exists == false"
    severity: critical
    action: immediate_notify
    
  - name: no_upgrade_48h
    condition: "time_since_last_upgrade > 48h"
    severity: warning
    action: log_warning
```

## 五、运维手册

### 5.1 安装

```bash
# 1. 复制服务文件
sudo cp config/systemd/sensen-self-upgrade.service /etc/systemd/system/
sudo cp config/systemd/sensen-self-upgrade.timer /etc/systemd/system/

# 2. 重载systemd
sudo systemctl daemon-reload

# 3. 启用并启动服务
sudo systemctl enable sensen-self-upgrade.timer
sudo systemctl start sensen-self-upgrade.timer

# 4. 验证
systemctl list-timers --all | grep sensen
```

### 5.2 常用命令

```bash
# 查看服务状态
systemctl status sensen-self-upgrade.service

# 查看定时器状态
systemctl status sensen-self-upgrade.timer

# 手动触发升级
systemctl start sensen-self-upgrade.service

# 停止服务
systemctl stop sensen-self-upgrade.service

# 重启服务
systemctl restart sensen-self-upgrade.service

# 查看日志
journalctl -u sensen-self-upgrade.service -n 100 -f
```

### 5.3 故障排查

#### 场景1: 服务无法启动

```bash
# 检查日志
journalctl -u sensen-self-upgrade.service --no-pager

# 检查脚本存在性
ls -la scripts/intelligence-*.py

# 检查权限
ls -la logs/
```

#### 场景2: 升级周期失败

```bash
# 查看详细日志
tail -n 200 logs/self-upgrade-daemon.log

# 手动运行评估脚本
python3 scripts/intelligence-assessment.py

# 检查依赖
python3 -c "import psutil; print('OK')"
```

#### 场景3: 定时器不触发

```bash
# 检查定时器状态
systemctl status sensen-self-upgrade.timer

# 列出所有定时器
systemctl list-timers --all

# 手动触发
systemctl start sensen-self-upgrade.service
```
