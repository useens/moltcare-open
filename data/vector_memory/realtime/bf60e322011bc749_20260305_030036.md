## 2. 搜索数据流

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         搜索流程 (Search Flow)                           │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│   Step 1: 查询输入                                                       │
│   ┌─────────────────────────────────────────────────────────────┐      │
│   │  User Input: "security audit findings"                      │      │
│   │  Filters: {type: "intel", importance: ">0.8"}               │      │
│   │  TopK: 5                                                    │      │
│   └─────────────────────────┬───────────────────────────────────┘      │
│                             │                                          │
│                             ▼                                          │
│   Step 2: 查询解析                                                       │
│   ┌─────────────────────────────────────────────────────────────┐      │
│   │  Query Parser                                               │      │
│   │  ├── 提取关键词: ["security", "audit", "findings"]          │      │
│   │  ├── 提取过滤器: type="intel", importance>0.8              │      │
│   │  └── 构建查询向量: [...384维...]                            │      │
│   └─────────────────────────┬───────────────────────────────────┘      │
│                             │                                          │
│                             ▼                                          │
│   Step 3: 语义搜索                                                       │
│   ┌─────────────────────────────────────────────────────────────┐      │
│   │  Vector Store Search                                        │      │
│   │  ├── 执行向量相似度计算 (cosine similarity)                  │      │
│   │  ├── 应用过滤器 (WHERE type='intel' AND importance>0.8)     │      │
│   │  └── 返回候选结果 (Top 20)                                  │      │
│   │       │                                                     │      │
│   │       ├── Result 1: score=0.92, id=2026-02-09#5             │      │
│   │       ├── Result 2: score=0.88, id=2026-02-08#12            │      │
│   │       ├── Result 3: score=0.85, id=2026-02-07#3             │      │
│   │       └── ...                                               │      │
│   └─────────────────────────┬───────────────────────────────────┘      │
│                             │                                          │
│                             ▼                                          │
│   Step 4: 关键词搜索 (可选，混合模式)                                      │
│   ┌─────────────────────────────────────────────────────────────┐      │
│   │  Keyword Search (FTS5)                                      │      │
│   │  ├── 查询: content MATCH 'security AND audit'               │      │
│   │  └── 返回关键词匹配结果                                      │      │
│   └─────────────────────────┬───────────────────────────────────┘      │
│                             │                                          │
│                             ▼                                          │
│   Step 5: 结果融合                                                         │
│   ┌─────────────────────────────────────────────────────────────┐      │
│   │  Hybrid Fusion                                              │      │
│   │  ├── 语义权重: 0.7                                          │      │
│   │  ├── 关键词权重: 0.3                                        │      │
│   │  ├── 最终分数 = 0.7 * semantic_score + 0.3 * keyword_score  │      │
│   │  └── 重新排序                                                │      │
│   └─────────────────────────┬───────────────────────────────────┘      │
│                             │                                          │
│                             ▼                                          │
│   Step 6: 结果返回                                                       │
│   ┌─────────────────────────────────────────────────────────────┐      │
│   │  Final Results (Top 5)                                      │      │
│   │  ┌───────────────────────────────────────────────────────┐  │      │
│   │  │ 1. [0.94] Security Audit Report - Feb 9               │  │      │
│   │  │    Source: memory/intel/security-audit-2026-02-09.md  │  │      │
│   │  ├───────────────────────────────────────────────────────┤  │      │
│   │  │ 2. [0.89] Vulnerability Findings Summary              │  │      │
│   │  │    Source: memory/daily/2026-02-09.md                 │  │      │
│   │  ├───────────────────────────────────────────────────────┤  │      │
│   │  │ 3. [0.85] Penetration Test Results                    │  │      │
│   │  │    Source: memory/intel/pentest-2026-02-08.md         │  │      │
│   │  └───────────────────────────────────────────────────────┘  │      │
│   └─────────────────────────────────────────────────────────────┘      │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

## 3. 自动关联数据流

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    自动关联流程 (Auto-Linking Flow)                       │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│   Trigger: 新记忆入库 或 手动触发                                         │
│                             │                                          │
│                             ▼                                          │
│   ┌─────────────────────────────────────────────────────────────┐      │
│   │  Step 1: 获取新记忆向量                                      │      │
│   │  ├── Memory ID: 2026-02-09#new                              │      │
│   │  ├── Content: "New security finding: SQL injection in..."   │      │
│   │  └── Vector: [0.12, -0.05, 0.33, ...]                       │      │
│   └─────────────────────────┬───────────────────────────────────┘      │
│                             │                                          │
│                             ▼                                          │
│   ┌─────────────────────────────────────────────────────────────┐      │
│   │  Step 2: 相似度搜索 (排除自身)                                │      │
│   │  ├── Query: vector of 2026-02-09#new                        │      │
│   │  ├── TopK: 10                                               │      │
│   │  └── Results:                                               │      │
│   │       │                                                     │      │
│   │       ├── 1. 2026-02-08#3 (similarity: 0.92)               │      │
│   │       ├── 2. 2026-02-07#1 (similarity: 0.78)               │      │
│   │       ├── 3. 2026-02-05#5 (similarity: 0.71)               │      │
│   │       └── ...                                               │      │
│   └─────────────────────────┬───────────────────────────────────┘      │
│                             │                                          │
│                             ▼                                          │
│   ┌─────────────────────────────────────────────────────────────┐      │
│   │  Step 3: 阈值过滤                                           │      │
│   │  ├── Threshold: 0.75                                        │      │
│   │  ├── Filtered:                                              │      │
│   │  │   ├── 2026-02-08#3 (0.92) ✓                             │      │
│   │  │   ├── 2026-02-07#1 (0.78) ✓                             │      │
│   │  │   └── 2026-02-05#5 (0.71) ✗ (filtered out)             │      │
│   │  └── Keep: 2 candidates                                     │      │
│   └─────────────────────────┬───────────────────────────────────┘      │
│                             │                                          │
│                             ▼                                          │
│   ┌─────────────────────────────────────────────────────────────┐      │
│   │  Step 4: 关联类型判定                                        │      │
│   │  ├── 2026-02-08#3:                                          │      │
│   │  │   ├── Same date prefix → temporal link?                  │      │
│   │  │   ├── High similarity → semantic link                    │      │
│   │  │   └── Same tags → tag link                               │      │
│   │  │   └── Decision: semantic (primary) + temporal (secondary)│      │
│   │  │                                                          │      │
│   │  └── 2026-02-07#1:                                          │      │
│   │      ├── Different date                                     │      │
│   │      ├── Medium similarity                                  │      │
│   │      └── Decision: semantic                                 │      │
│   └─────────────────────────┬───────────────────────────────────┘      │
│                             │                                          │
│                             ▼                                          │
│   ┌─────────────────────────────────────────────────────────────┐      │
│   │  Step 5: 存储关联                                            │      │
│   │  ├── INSERT INTO memory_links                               │      │
│   │  │   (source_id, target_id, similarity, link_type)          │      │
│   │  │ VALUES                                                   │      │
│   │  │   ('2026-02-09#new', '2026-02-08#3', 0.92, 'semantic'), │      │
│   │  │   ('2026-02-09#new', '2026-02-07#1', 0.78, 'semantic'); │      │
│   │  └── Commit transaction                                     │      │
│   └─────────────────────────┬───────────────────────────────────┘      │
│                             │                                          │
│                             ▼                                          │
│   ┌─────────────────────────────────────────────────────────────┐      │
│   │  Step 6: 更新记忆图谱                                        │      │
│   │  ├── Add node: 2026-02-09#new                               │      │
│   │  ├── Add edge: 2026-02-09#new → 2026-02-08#3 (weight: 0.92) │      │
│   │  ├── Add edge: 2026-02-09#new → 2026-02-07#1 (weight: 0.78) │      │
│   │  └── Recalculate clusters                                   │      │
│   └─────────────────────────────────────────────────────────────┘      │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

│                                                                         │
│   Input: Index Directory Request                                        │
│   └── Path: "memory/"                                                   │
│       Pattern: "*.md"                                                   │
│       Recursive: True                                                   │
│                                                                         │
│   ┌─────────────────────────────────────────────────────────────────┐  │
│   │  Step 1: 文件发现                                                │  │
│   │  ├── Scan memory/                                               │  │
│   │  ├── Find 150 .md files                                         │  │
│   │  └── Filter:                                                    │  │
│   │       ├── Skip already indexed (unchanged): 120 files          │  │
│   │       └── Need to index: 30 files                              │  │
│   └─────────────────────────┬───────────────────────────────────────┘  │
│                             │                                          │
│                             ▼                                          │
│   ┌─────────────────────────────────────────────────────────────────┐  │
│   │  Step 2: 文件分组                                                │  │
│   │  ├── Group by size:                                             │  │
│   │  │   ├── Small (<10KB): 20 files                               │  │
│   │  │   └── Large (>10KB): 10 files                               │  │
│   │  └── Create batches of 32 files each                            │  │
│   └─────────────────────────┬───────────────────────────────────────┘  │
│                             │                                          │
│                             ▼                                          │
│   ┌─────────────────────────────────────────────────────────────────┐  │
│   │  Step 3: 并行处理 (Batch 1/1)                                    │  │
│   │  ┌─────────────────────────────────────────────────────────┐   │  │
│   │  │  Worker 1: file1.md, file2.md, ..., file8.md            │   │  │
│   │  ├─────────────────────────────────────────────────────────┤   │  │
│   │  │  Worker 2: file9.md, file10.md, ..., file16.md          │   │  │
│   │  ├─────────────────────────────────────────────────────────┤   │  │
│   │  │  Worker 3: file17.md, file18.md, ..., file24.md         │   │  │
│   │  ├─────────────────────────────────────────────────────────┤   │  │
│   │  │  Worker 4: file25.md, file26.md, ..., file30.md         │   │  │
│   │  └─────────────────────────────────────────────────────────┘   │  │
│   └─────────────────────────┬───────────────────────────────────────┘  │
│                             │                                          │
│                             ▼                                          │
│   ┌─────────────────────────────────────────────────────────────────┐  │
│   │  Step 4: 解析与分块                                              │  │
│   │  ├── Parse markdown                                             │  │
│   │  ├── Extract metadata                                           │  │
│   │  ├── Chunk into segments                                        │  │
│   │  └── Total chunks: 150                                          │  │
│   └─────────────────────────┬───────────────────────────────────────┘  │
│                             │                                          │
│                             ▼                                          │
│   ┌─────────────────────────────────────────────────────────────────┐  │
│   │  Step 5: 批量编码                                                │  │
│   │  ├── Embedder.encode_batch(chunks, batch_size=32)               │  │
│   │  ├── Generate 150 embeddings [150 x 384]                        │  │
