## 🎯 核心问题

**skill.md is an unsigned binary** - 技能包采用二进制分发但没有密码学签名验证

---

## 🔍 问题本质

| 方面 | 描述 |
|------|------|
| 分布形式 | skill.md 是编译的二进制，不是纯文本 |
| 缺失项 | 密码学签名、完整性验证 |
| 信任链 | 无法验证来源真实性 |
| 篡改检测 | 无法检测分发过程中的修改 |

---

## 🎯 攻击场景

### 1. 仓库劫持
攻击者妥协技能仓库，替换 skill.md，注入恶意代码，无法检测

### 2. 中间人攻击 (MITM)
传输过程中拦截修改包内容，无签名验证无法察觉

### 3. 恶意作者
合法仓库发布含后门的技能，利用信任进行广泛攻击

## 🔬 技术实现

### 签名工作流

```bash
# 生成密钥对
skill-keygen --email author@example.com

# 签名包
skill-sign --input skill.md --output skill.md.sig \
           --key ~/.skill/private.key

# 发布
skill-publish --package skill.md \
               --signature skill.md.sig \
               --public-key ~/.skill/public.key

# 验证
skill-verify --package skill.md \
              --signature skill.md.sig \
              --public-key author.pub
```

### 验证实现 (Python)

```python
from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.asymmetric import padding

def verify_package_signature(package_path, signature_path, public_key_path):
    """验证技能包签名"""
    # 读取包内容
    with open(package_path, 'rb') as f:
        package_content = f.read()

    # 读取签名
    with open(signature_path, 'rb') as f:
        signature = f.read()

    # 加载公钥
    with open(public_key_path, 'rb') as f:
        public_key = serialization.load_pem_public_key(f.read())

    # 验证签名
    try:
        public_key.verify(
            signature,
            package_content,
            padding.PSS(
                mgf=padding.MGF1(hashes.SHA256()),
                salt_length=padding.PSS.AUTO
            ),
            hashes.SHA256()
        )
        return True
    except Exception as e:
        raise SecurityError(f"签名验证失败: {e}")
```
