## ⚡ FSRS+Signal 记忆优先级公式

### 综合优先级计算

```
最终优先级 = α * Signal + β * FSRS_紧急因子

其中：
- α = 0.4 (Signal权重)
- β = 0.6 (FSRS权重)
- Signal = 用户重要性评分 (1-10)
- FSRS_紧急因子 = (1 - Retrievability) × 10
  - Retrievability = (1 + elapsed_days / (9×stability))^(-1)
```

### 优先级队列生成

```python
from core.vestige_memory import VestigeMemory

vm = VestigeMemory()
priority_queue = vm.get_priority_queue(limit=20)

# 返回格式:
# [(MemoryItem, combined_priority), ...]
# 按combined_priority降序排列
```

## 🎓 FSRS-6 算法总结

### 核心公式

```
1. 可提取性 R(t, s) = (1 + t/(9×s))^(-1)
   - t = 经过天数
   - s = 稳定性
   - R ∈ [0, 1]

2. 下次稳定性 S'
   - rating=1 (忘记): S' = S × 0.5 × difficulty_factor
   - rating=2 (困难): S' = S × 1.1 × difficulty_factor
   - rating=3 (良好): S' = S × 1.8 × difficulty_factor
   - rating=4 (简单): S' = S × 2.5 × difficulty_factor

3. 下次难度 D'
   - rating=1: D' = min(10, D + 1)
   - rating=2: D' = min(10, D + 0.3)
   - rating=3: D' = max(1, D - 0.1)
   - rating=4: D' = max(1, D - 0.3)

4. 复习间隔 I = S × ln(R) / ln(0.9)
```

### 参数说明

- **Difficulty (D)**: 难度 1-10，越高越难
- **Stability (S)**: 稳定性 (天数)，越高间隔越长
- **Retrievability (R)**: 可提取性 0-1，越高越容易回忆
