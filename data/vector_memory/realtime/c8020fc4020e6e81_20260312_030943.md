# MOLTCARE.md - Moltcare 开源项目使命书

> 🦞 **创建时间**: 2026-03-11  
> **项目地址**: https://github.com/useens/moltcare-open  
> **核心使命**: 让所有新安装的龙虾（OpenClaw agents）一键提升智能

---

## 🎯 项目愿景

**Moltcare** 是一个开源的 Agent 智能提升框架，专为 OpenClaw 生态系统设计。

> 每只新孵化的龙虾都值得拥有优秀的核心文件和智能行为能力。

---

## 🌟 核心功能

| 功能模块 | 描述 | 状态 |
|----------|------|------|
| **智能诊断** | 自动分析 Agent 核心文件质量 | 🔄 开发中 |
| **一键修复** | 基于最佳实践自动优化核心文件 | 🔄 开发中 |
| **双AI协作** | GitHub 上两个AI自动协作开发 | 🔄 开发中 |
| **多专家讨论** | 重要开发阶段强制开启专家审议 | 🔄 开发中 |
| **模板库** | 高质量核心文件模板集合 | 🔄 开发中 |

## 👥 多专家角色定义

| 角色 | 职责 | 触发条件 |
|------|------|----------|
| **架构师** | 设计整体方案、模块划分 | 项目启动时 |
| **代码专家** | 编写核心代码、工具实现 | 功能开发阶段 |
| **审查员** | 代码审查、质量把关 | 每轮PR提交时 |
| **测试员** | 测试验证、场景覆盖 | 功能完成时 |
| **文档员** | 文档编写、使用指南 | 每个里程碑 |
