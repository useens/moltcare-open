## 双AI协作流程

1. **Agent A (开发者)** 创建功能分支并提交代码
2. **Agent B (审查者)** 自动审查并提交 review
3. **共识达成** 后合并到 main
4. **多专家讨论** 在关键决策点触发

## 多专家角色

- 🏗️ **架构师**: 系统设计、模块划分
- 💻 **开发者**: 代码实现、功能开发  
- 🔍 **审查员**: 代码审查、质量把控
- 🧪 **测试员**: 测试覆盖、场景验证
- 📝 **文档员**: 文档编写、使用指南
