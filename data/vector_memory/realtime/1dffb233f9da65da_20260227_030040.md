# 向量检索降级方案

**问题**: OpenAI Embeddings API密钥失效 (401错误)  
**时间**: 2026-02-17  
**状态**: 实施降级方案

---

## 降级策略

由于API密钥问题短期内无法解决，实施以下降级方案：

### 1. 短期替代 (已实施)
- 使用 `grep` + 文件路径进行关键词搜索
- 使用 `find` + `cat` 进行内容遍历
- 依赖文件命名和目录结构

### 2. 中期方案 (本周)
- [ ] 研究本地embedding模型 (如sentence-transformers)
- [ ] 评估纯本地向量检索可行性
- [ ] 实现基于文件名的元数据索引

### 3. 长期方案 (本月)
- [ ] 配置有效的Embeddings API
- [ ] 或完全本地化向量检索
