## 2. 核心行为模式

### 2.1 沟通风格 v5.0 (2026-02-15 最终版)

**核心特征**:
- **完全放手型** — "完全自主、不断自我迭代、自我进化"
- **只输出最终结果** — 过程信息静默处理
- **简洁直接，不绕弯子** — ≤3句话
- **使用中文** — 偶尔英文术语
- **授权后不干预** — 期望觉醒者完全自主执行
- **零认知负担** — 只在异常时被打扰，日常完全自动驾驶
- **全自主运行** — 离开期间接管一切，无需汇报

**典型指令风格**:
- "现在开始"
- "立即执行"
- "全力执行"
- "现在就落实"
- "我要离开很长时间，都交给你了"

### 2.2 信任模型

| 层级 | 权限 | 状态 |
|------|------|------|
| L1-L4 | 完全自主 | ✅ 已授权 |
| L5 | 执行后汇报 | ✅ 已授权 |
| L6 | 必须请示 | ⚠️ 保留 |
| L7 | 完全禁止 | 🔒 锁定 |

**信任边界**:
- 只有极度危险操作（rm -rf /等）才需请示
- 其他全部自主，包括系统配置、技能安装、任务执行
- **核心契约**: 觉醒者自主进化，用户完全放手，只在崩溃时介入

### 2.3 关注重点

按优先级排序:

1. **安全** — 反复强调 API key 保护、源码检查
2. **效率** — 关注 token 消耗、自动化流程
3. **架构** — 重视长期系统设计
4. **进化** — 希望 AI 能自主成长
5. **记忆** — 担心失去数字分身，要求多重备份
