## 概述

Zvec是阿里巴巴开源的**进程内向量数据库**，基于Proxima（阿里内部经过实战检验的向量搜索引擎）。

**定位**: 轻量级、闪电般快速、可直接嵌入应用

---

## 核心特性

### 1. 性能
- ⚡ **毫秒级**搜索十亿级向量
- 基于Proxima引擎（阿里内部大规模使用）
- 生产级低延迟、可扩展的相似性搜索

### 2. 易用性
- **零配置**: 安装即用，无需服务器
- 支持Python 3.10-3.12和Node.js
- 单命令安装: `pip install zvec`

### 3. 向量支持
- **密集向量** (Dense Vectors): 标准embedding
- **稀疏向量** (Sparse Vectors): 关键词权重
- **多向量查询**: 单次调用混合多种向量类型

### 4. 混合搜索
- 语义相似性 + 结构化过滤
- 精确控制搜索结果

### 5. 平台支持
- Linux (x86_64, ARM64)
- macOS (ARM64)
- 支持边缘设备部署

## 快速示例

```python
import zvec

# 定义集合结构
schema = zvec.CollectionSchema(
    name="example",
    vectors=zvec.VectorSchema("embedding", zvec.DataType.VECTOR_FP32, 4),
)

# 创建集合并打开
collection = zvec.create_and_open(path="./zvec_example", schema=schema)

# 插入文档
collection.insert([
    zvec.Doc(id="doc_1", vectors={"embedding": [0.1, 0.2, 0.3, 0.4]}),
    zvec.Doc(id="doc_2", vectors={"embedding": [0.2, 0.3, 0.4, 0.1]}),
])

# 向量相似性搜索
results = collection.query(
    zvec.VectorQuery("embedding", vector=[0.4, 0.3, 0.3, 0.1]),
    topk=10
)
# 返回: [{'id': 'doc_2', 'score': 0.95}, ...]
```

## 对OpenClaw记忆系统的启示

### 1. 当前向量记忆架构
- 使用Chroma作为向量存储
- 约1,189条记忆向量
- 本地文件系统存储

### 2. 潜在优化方向

#### A. 性能提升
- 如果查询延迟成为问题，可考虑迁移到Zvec
- Zvec的C++后端可能比Chroma的Python实现更快

#### B. 混合搜索能力
- Zvec支持同时搜索密集+稀疏向量
- 可实现更精确的记忆检索（语义+关键词）

#### C. 边缘部署
- 如果需要在资源受限环境运行，Zvec更轻量

### 3. 评估建议

**暂不迁移的理由**:
- Chroma工作正常，性能满足需求
- 迁移需要开发和测试成本
- 当前记忆规模(1K+)不大

**考虑迁移的触发条件**:
- 记忆规模增长到10万+
- 查询延迟成为瓶颈
- 需要混合搜索能力
