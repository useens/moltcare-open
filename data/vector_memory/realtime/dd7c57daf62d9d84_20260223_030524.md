## 🧠 核心功能

### 1. 记忆价值计算

**算法**: `价值 = 基础分 × 时间衰减 + 访问加分`

```python
基础分: 1-10 (重要性)
时间衰减: 30天后保留30%
访问加分: 每次访问+0.2分 (上限2分)
永不忘: 用户指令/里程碑 = 9-10分
```

### 2. 三级记忆管理

| 层级 | 条件 | 操作 |
|------|------|------|
| **活跃记忆** | 价值 ≥ 5 | 正常检索 |
| **归档记忆** | 3 ≤ 价值 < 5 | 移至冷存储 |
| **遗忘记忆** | 价值 < 3 | 永久删除 (极少) |

### 3. 相似记忆压缩

- 阈值: 余弦相似度 ≥ 0.85
- 触发: 6条以上相似记忆
- 结果: 合并为摘要记忆

---

## ⏰ 遗忘周期

**自动执行**: 每天凌晨2点 (配合夜间进化)

**流程**:
1. 计算所有记忆价值
2. 归档低价值记忆 (3-5分)
3. 压缩相似记忆组
4. 遗忘极低价值记忆 (<3分)
