## 1. FSRS-6核心算法概述

### 1.1 算法起源
- **来源**: Free Spaced Repetition Scheduler (FSRS)
- **基础**: 基于MaiMemo的DHP模型，是DSR (Difficulty, Stability, Retrievability) 模型的变体
- **研究基础**: 130年记忆科学研究成果

### 1.2 核心思想
FSRS-6通过以下三个关键参数描述记忆状态：

| 参数 | 符号 | 范围 | 说明 |
|------|------|------|------|
| 稳定性 | S | (0, ∞) | 记忆保持90%时的时间间隔（天） |
| 难度 | D | [1, 10] | 卡片难度，1=最简单，10=最难 |
| 可提取性 | R | [0, 1] | 当前时刻回忆的概率 |

### 1.3 评分等级 (Grade/Rating)
- 1: Again (忘记)
- 2: Hard (困难)
- 3: Good (良好)
- 4: Easy (简单)

## 3. 间隔计算公式

### 3.1 遗忘曲线 (Forgetting Curve)

**FSRS-6公式**:
```
R(t, S) = (1 + factor × t/S)^(-DECAY)

其中:
- DECAY = w20 = 0.1542
- factor = 0.9^(-1/DECAY) - 1 = 4.9371
```

**特性**:
- R(S, S) = 90% (当t = S时，回忆概率为90%)
- 遗忘曲线在S之前下降较快，之后趋于平缓

### 3.2 下次间隔计算 (Next Interval)

**公式**:
```
I(r, S) = S / FACTOR × (r^(1/DECAY) - 1)

其中:
- r = 期望保持率 (desired retention)
- S = 当前稳定性
```

### 3.3 初始稳定性 (Initial Stability)

**公式**:
```
S0(G) = w[G-1]

示例:
- S0(1) = w0 = 0.212  (Again)
- S0(3) = w2 = 2.3065 (Good)
- S0(4) = w3 = 8.2956 (Easy)
```

### 3.4 初始难度 (Initial Difficulty)

**公式**:
```
D0(G) = w4 - e^(w5 × (G-1)) + 1

示例:
- D0(1) = w4 - e^(0) + 1 = w4
- D0(3) = w4 - e^(2w5) + 1
- D0(4) = w4 - e^(3w5) + 1
```

### 3.5 成功后新稳定性 (Stability After Success)

**公式** (FSRS-6):

```
S'_r(D, S, R, G) = S × [e^w8 × (11-D) × S^(-w9) × (e^(w10×(1-R)) - 1) × penalty × bonus + 1]

其中:
- penalty = w15 (当G=2/Hard时)
- bonus = w16 (当G=4/Easy时)
```

**关键特性**:
1. **难度效应**: D越大，S增长越小（难的知识更难巩固）
2. **稳定性效应**: S越大，S增长越小（高稳定性内容更难提升）
3. **间隔效应**: R越小，S增长越大（延迟复习增加记忆效果）
4. **边界**: S≥1（成功后稳定性不会减少）

### 3.6 失败后新稳定性 (Stability After Failure)

**公式**:

```
S'_f(D, S, R) = w11 × D^(-w12) × ((S+1)^w13 - 1) × e^(w14×(1-R))
```

**特性**:
- 失败后稳定性大幅降低，但不完全重置
- 难度越高，恢复后的稳定性越低
- 旧稳定性越高，恢复后的稳定性越高

### 3.7 同日复习稳定性 (Same-Day Review Stability)

**FSRS-6新增公式**:

```
S'_short(S, G) = S × [e^(w17×(G-3+w18)) × S^(-w19)]

约束条件:
- 当G≥3时，确保增长率≥1
```

**意义**:
- 支持一天内多次复习
- 稳定性在小时级提升更快，在分钟级提升更慢
- 避免同日无限刷题

### 3.8 难度更新 (Difficulty Update)

**步骤1: 线性阻尼**

```
ΔD(G) = -w6 × (G-3)
D' = D + ΔD × (10-D)/9
```

**步骤2: 均值回归**

```
D'' = w7 × D0(4) + (1-w7) × D'
```

**最终约束**: D'' ∈ [1, 10]

**说明**:
- 使用D0(4)（Easy的初始难度）作为回归目标
- 防止"Ease Hell"（难度无限降低）

## 4. 算法执行流程

### 4.1 单张卡片复习状态更新

```rust
fn step(delta_t, rating, state, nth) -> MemoryState {
    // 1. 计算当前可提取性
    R = power_forgetting_curve(delta_t, state.S)

    // 2. 计算三种可能的稳定性
    S_success = stability_after_success(S, D, R, G)
    S_failure = stability_after_failure(S, D, R)
    S_short = stability_short_term(S, G)

    // 3. 根据评分选择稳定性
    if rating == 1:  // Again
        new_S = S_failure
    elif delta_t == 0:  // 同日复习
        new_S = S_short
    else:  // 成功
        new_S = S_success

    // 4. 更新难度
    new_D = next_difficulty(D, G)
    new_D = mean_reversion(new_D)

    // 5. 初始卡片特殊处理
    if nth == 0 and state.S == 0:
        new_S = init_stability(G)
        new_D = init_difficulty(G)

    // 6. 边界约束
    new_S = clamp(new_S, S_MIN, S_MAX)
    new_D = clamp(new_D, D_MIN, D_MAX)

    return MemoryState(new_S, new_D)
}
```

### 4.2 下次状态预测 (Next States)

```rust
fn next_states(current_state, desired_retention, days_elapsed) -> NextStates {
    // 对每个评分(1-4):
    for rating in [1, 2, 3, 4]:
        // 1. 更新记忆状态
        new_state = step(days_elapsed, rating, current_state, nth)

        // 2. 计算下次间隔
        interval = next_interval(new_state.S, desired_retention)

        // 3. 返回结果
        states[rating] = ItemState(new_state, interval)

    return {
        again: states[1],
        hard: states[2],
        good: states[3],
        easy: states[4]
    }
}
```

```python
def adjust_difficulty(D0: float, signal_score: float) -> float:
    """根据Signal评分调整初始难度"""
    # Signal分数越低，难度越高
    difficulty_adjustment = (1.0 - signal_score) * 2.0
    new_difficulty = D0 + difficulty_adjustment
    return clamp(new_difficulty, 1.0, 10.0)
```

### 5.4 集成方案 C: 混合评分权重

```python
def hybrid_rating(signal_score: float, user_rating: int) -> int:
    """结合Signal自动评分和用户手动评分"""
    base_score = signal_score * 10  # 0-10分

    # 用户评分可覆盖
    if user_rating:
        fsrs_from_user = {1: 1, 2: 4, 3: 7, 4: 10}[user_rating]
        # 加权平均: Signal 60%, 用户 40%
        combined = base_score * 0.6 + fsrs_from_user * 0.4
    else:
        combined = base_score

    # 转换回1-4
    if combined <= 2.5:
        return 1
    elif combined <= 5.0:
        return 2
    elif combined <= 7.5:
        return 3
    else:
        return 4
```

## 6. 关键代码片段

### 6.1 遗忘曲线实现 (Rust)

```rust
pub fn power_forgetting_curve(&self, t: Tensor<B, 1>, s: Tensor<B, 1>) -> Tensor<B, 1> {
    let decay = -self.w.get(20);  // w20 = 0.1542
    let factor = decay.clone().powi_scalar(-1).mul_scalar(0.9f32.ln()).exp() - 1.0;
    (t / s * factor + 1.0).powf(decay)
}
```

### 6.2 下次间隔计算

```rust
pub fn next_interval(
    &self,
    stability: Tensor<B, 1>,
    desired_retention: Tensor<B, 1>,
) -> Tensor<B, 1> {
    let decay = -self.w.get(20);
    let factor = decay.clone().powi_scalar(-1).mul_scalar(0.9f32.ln()).exp() - 1.0;
    stability / factor * (desired_retention.powf(decay.powi_scalar(-1)) - 1.0)
}
```

### 6.3 成功后稳定性更新

```rust
fn stability_after_success(
    &self,
    last_s: Tensor<B, 1>,
    last_d: Tensor<B, 1>,
    r: Tensor<B, 1>,
    rating: Tensor<B, 1>,
) -> Tensor<B, 1> {
    let batch_size = rating.dims()[0];
    let device = rating.device();

    // Hard评分惩罚
    let hard_penalty = Tensor::ones([batch_size], &device)
        .mask_where(rating.clone().equal_elem(2), self.w.get(15));

    // Easy评分奖励
    let easy_bonus = Tensor::ones([batch_size], &device)
        .mask_where(rating.equal_elem(4), self.w.get(16));

    last_s.clone()
        * (self.w.get(8).exp()               // e^w8
            * (-last_d + 11)                 // (11-D)
            * (last_s.powf(-self.w.get(9)))  // S^-w9
            * (((-r + 1) * self.w.get(10)).exp() - 1)  // (e^(w10×(1-R)) - 1)
            * hard_penalty
            * easy_bonus
            + 1)
}
```

### 6.4 同日复习稳定性 (FSRS-6新增)

```rust
fn stability_short_term(&self, last_s: Tensor<B, 1>, rating: Tensor<B, 1>) -> Tensor<B, 1> {
    let sinc = (self.w.get(17) * (rating.clone() - 3 + self.w.get(18))).exp()
        * last_s.clone().powf(-self.w.get(19));

    last_s
        * sinc
            .clone()
            .mask_where(rating.greater_equal_elem(2), sinc.clamp_min(1.0))
}
```

## 8. 核心特性总结

### 8.1 FSRS-6相对于FSRS-5的改进

1. **可训练的遗忘曲线 decay (w20)**
   - 旧版本固定 decay = -0.5
   - FSRS-6: decay = 0.1542（可从数据训练）

2. **同日复习稳定性公式改进**
   - 旧版本: `S' = S × e^(w17×(G-3))`
   - FSRS-6: `S' = S × e^(w17×(G-3+w18)) × S^(-w19)`
   - 增加 w18 和 w19 两个参数，实现收敛控制

3. **参数数量**
   - FSRS-5: 19个参数
   - FSRS-6: 21个参数

### 8.2 Vestige的FSRS实现特点

1. **100%本地运行** - 无云依赖
2. **语义搜索** - 结合向量嵌入
3. **自动衰减** - 未使用的记忆自然淡化
4. **间隔重复** - FSRS-6优化复习时机
5. **传播激活** - 相关记忆互相强化
6. **突触标记** - 重要记忆持久化

### 8.3 适用场景

## 9. 实现建议

### 9.1 Signal与FSRS集成流程

```python
class HybridMemorySystem:
    def __init__(self):
        self.fsrs = FSRS(default_parameters)
        self.signal_model = load_signal_model()

    def review_memory(self, memory_id, query_attempt):
        # 1. 获取Signal评分
        signal_score = self.signal_model.score(query_attempt)

        # 2. 转换为FSRS评级
        fsrs_rating = signal_to_fsrs_rating(signal_score)

        # 3. 获取当前记忆状态
        current_state = self.get_memory_state(memory_id)

        # 4. 计算下次状态
        next_states = self.fsrs.next_states(
            current_state=current_state,
            desired_retention=0.9,
            days_elapsed=self.get_days_since_last_review(memory_id)
        )

        # 5. 保存新状态
        new_state = next_states.state_for_rating(fsrs_rating)
        self.save_memory_state(memory_id, new_state.state)
        self.schedule_next_review(memory_id, new_state.interval)

        return new_state
```
