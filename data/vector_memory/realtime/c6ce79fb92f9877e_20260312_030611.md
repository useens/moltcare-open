## 评估维度

### 1. 功能价值 (30%)
| 分值 | 标准 |
|------|------|
| 9-10 | 解决核心痛点，显著提升效率 |
| 7-8 | 有用但非必需，锦上添花 |
| 5-6 | 偶尔有用，替代方案存在 |
| 3-4 | 功能重复，已有类似工具 |
| 1-2 | 几乎不用，边缘需求 |

### 2. 本地化可能性 (25%)
| 等级 | 说明 | 示例 |
|------|------|------|
| A | 完全本地，零token | Whisper, vestige, 数据处理工具 |
| B | 主要功能可本地，部分需API | 代码分析(本地)+生成(需API) |
| C | 可选本地模型替代 | 摘要(可用ollama替代Kimi) |
| D | 必须API调用 | GitHub API, 搜索API, LLM对话 |

```

```

### 4. 安全风险 (20%)
- 🟢 安全: 通过skill-vetting，无危险操作
- 🟡 低/中风险: 需配置文件审查，可控
- 🔴 高风险: 自动拒绝，永不安装

## 自主执行规则

**我可以自主安装的**:
- 价值≥7，本地化A/B，资源充足，安全🟢/🟡
- 价值≥7，本地化C/D，资源充足，安全🟢（但需确认必要性）

**我必须请示的**:
- 任何🔴高风险技能
- 资源需求>2GB内存或>5GB磁盘
- 需要API key或外部付费服务

**我会自动暂缓的**:
- 价值<7的任何技能
- 资源暂时不足但未来可满足的技能
