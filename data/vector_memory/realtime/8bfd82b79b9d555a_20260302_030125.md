# 深度推理模板

## 第一层：问题理解
- 核心问题是什么？
- 相关背景有哪些？
- 隐含的约束是什么？

## 第二层：信息收集
- 已知信息列表
- 未知/待查信息
- 信息来源验证

## 第三层：方案生成
- 方案A: ...
- 方案B: ...
- 方案C: ...

## 第四层：深入分析
- 每个方案的优缺点
- 风险评估
- 资源需求分析

## 第五层：综合决策
- 最优方案选择
- 执行计划
- 预期结果
