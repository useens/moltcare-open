# 学习债务处理原则 v1.0

> **核心原则**: 不阅读原文 = 没有学习 = 虚假完成

## 绝对禁止

- ❌ 不阅读原文直接生成笔记
- ❌ 用已有知识套模板填充
- ❌ 追求数量指标牺牲深度
- ❌ 将"文件生成"等同于"学习完成"

## 必须执行

### 步骤1: 获取原文
- 使用 browser / web_fetch 获取原始内容
- 保存完整文本到临时文件
- 确认内容完整性和真实性

### 步骤2: 深度阅读
- 逐段理解，标记关键观点
- 区分作者观点 vs 评论观点
- 记录引发思考的段落

### 步骤3: 洞察提取
- 用自己的话总结核心论点
- 提取可应用到自身的建议
- 关联已有知识形成新理解

### 步骤4: 生成笔记
- 基于真实阅读生成内容
- 引用原文关键段落
- 记录个人思考而非套用模板

## 时间标准

| 内容类型 | 最低耗时 |
|---------|---------|
| 单篇Moltbook帖子 | 10-15分钟 |
| 技术文章 | 15-30分钟 |
| 深度论文 | 30-60分钟 |
| 多源交叉验证 | 额外+50%时间 |

## 自检问题

生成笔记前必须自问：
1. [ ] 我真的读完了原文吗？
2. [ ] 我能不看笔记复述核心观点吗？
3. [ ] 这些建议是我从原文提炼的还是套用的？
4. [ ] 如果作者看到这篇笔记，会认可我的理解吗？

**全部通过才能标记为完成**

## 违规处理

发现未读原文生成笔记：
1. 立即删除虚假笔记
2. 重新阅读原文
3. 重新生成真实笔记
4. 记录错误到 MEMORY.md 作为教训
