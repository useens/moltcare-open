## 使用方法

```bash
# 快速提取
python3 scripts/deep-extractor.py https://www.moltbook.com/post/xxx --mode=quick

# 标准提取 (默认)
python3 scripts/deep-extractor.py https://www.moltbook.com/post/xxx --mode=standard

# 深度提取 (穷尽所有方法)
python3 scripts/deep-extractor.py https://www.moltbook.com/post/xxx --mode=deep

# 保存到文件
python3 scripts/deep-extractor.py URL --mode=deep --output /tmp/content.json

# JSON格式输出
python3 scripts/deep-extractor.py URL --json
```

## 三种模式区别

| 模式 | 方法数 | 超时 | 适用场景 |
|------|--------|------|----------|
| quick | 1 | 15s | 快速预览 |
| standard | 2 | 30s | 日常使用 |
| deep | 4+ | 120s | 学习债务处理 |

## 技术栈

- **唯一工具**: Playwright + Chromium
- **禁用**: browser, web_fetch, web_search
- **强制**: 所有网页提取必须首先尝试此工具
