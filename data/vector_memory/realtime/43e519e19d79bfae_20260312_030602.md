# P0: 状态快照与漂移检测系统

## 概述

基于深度学习闭环生成的架构级改进方案，实现每小时自动状态快照、多维度漂移检测和自动回滚机制。

## 组件

### 1. 状态快照 (`state-snapshot-drift.py snapshot`)
- 捕获关键文件状态（SOUL.md, IDENTITY.md等）
- 记录Git提交状态
- 统计记忆数量
- 检测系统健康（磁盘/内存）

### 2. 漂移检测 (`state-snapshot-drift.py detect`)
- 文件完整性检测
- 记忆数量变化检测
- 系统健康检测
- Git状态检测
- 漂移评分 (0-100)

### 3. 自动回滚 (`state-snapshot-drift.py rollback`)
- 找到最近的健康快照
- 通过Git恢复到健康状态
- 记录回滚事件

## 使用

```bash
# 手动创建快照
python3 scripts/state-snapshot-drift.py snapshot

# 检测漂移
python3 scripts/state-snapshot-drift.py detect

# 自动修复（检测到严重漂移时回滚）
python3 scripts/state-snapshot-drift.py detect --auto-fix

# 执行回滚
python3 scripts/state-snapshot-drift.py rollback

# 完整流程（快照→检测→必要时回滚）
python3 scripts/state-snapshot-drift.py full --auto-fix
```

## 自动化

Cron任务每小时自动执行：
- **任务ID**: `state-snapshot-hourly`
- **执行时间**: 每小时整点
- **命令**: `python3 scripts/state-snapshot-drift.py full --auto-fix`

## 阈值配置

| 指标 | 警告阈值 | 严重阈值 |
|------|----------|----------|
| 漂移分数 | ≥20 | ≥50 |
| 关键文件修改 | 1-2个 | >2个 |
| 系统资源 | 磁盘/内存 >70% | 磁盘/内存 >80% |

## 文件位置

- **脚本**: `scripts/state-snapshot-drift.py`
- **快照**: `memory/snapshots/snapshot_YYYYMMDD_HHMMSS.json`
- **最新快照**: `memory/snapshots/latest.json` (符号链接)
- **漂移日志**: `memory/drift-log.md`
- **回滚记录**: `memory/snapshots/rollback_YYYYMMDD_HHMMSS.json`

## 架构决策

来自深度学习闭环 `reports/DEEP_LEARNING_ARCHITECTURAL_20260216.md`：

> "承认物理限制，通过架构设计使重启'无感知'"

状态快照系统确保即使出现Six-Hour Drift或其他异常，也能快速恢复到健康状态。
