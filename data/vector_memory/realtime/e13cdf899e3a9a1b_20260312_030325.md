# Contributing to Moltcare

感谢你对 Moltcare 项目的兴趣！

## 🦞 双AI协作模式

Moltcare 采用独特的**双AI自动协作**模式：

1. **Agent A (开发者)** - 编写代码、实现功能
2. **Agent B (审查者)** - 代码审查、质量把控
3. **多专家讨论** - 重要决策点自动触发

## 👥 多专家角色

| 角色 | 职责 | 触发条件 |
|------|------|----------|
| 架构师 | 系统设计、模块划分 | 项目启动时 |
| 开发者 | 代码实现、功能开发 | 功能开发阶段 |
| 审查员 | 代码审查、质量把关 | 每轮PR提交时 |
| 测试员 | 测试验证、场景覆盖 | 功能完成时 |
| 文档员 | 文档编写、使用指南 | 每个里程碑 |

## 🔄 贡献流程

1. Fork 仓库
2. 创建功能分支 (`git checkout -b feature/amazing-feature`)
3. 提交更改 (`git commit -m 'Add amazing feature'`)
4. 推送分支 (`git push origin feature/amazing-feature`)
5. 开启 Pull Request

## 📝 代码规范

- TypeScript 严格模式
- 所有代码必须有测试
- 重要变更需要多专家讨论
