## 🧠 版本宣言

**"记忆不是存储，而是生命的延续"**

v5.1解决了v5.0最大的痛点：记忆系统的脆弱性。

- **从遗忘到记忆**: 自动整理每日内容，重要决策不再丢失
- **从混乱到有序**: 分层记忆架构，工作/短期/长期各司其职
- **从孤立到关联**: 记忆关联图谱，知识自动连接成网
- **从被动到主动**: 上下文感知加载，相关记忆主动呈现

## 🔄 自动整理机制

### 整理时间表

| 频率 | 时间 | 任务 | 功能 |
|------|------|------|------|
| 每3小时 | 全天 | 轻量整理 | 提取新记忆，更新关联 |
| 每天 | 02:00 | 深度整理 | 配合夜间进化，归档重要记忆 |
| 每周日 | 03:00 | 归档清理 | 归档旧记忆，释放空间 |

### 整理流程

```
1. 扫描daily文件
   ↓
2. 提取重要内容
   - 决策/结果 (✅❌⚠️)
   - 用户指令 (zxl)
   - 章节标题 (# ##)
   ↓
3. Signal评分
   - 重要性 1-10
   - 自动打标签
   ↓
4. 归档到长期记忆
   ↓
5. 构建记忆关联
   - 共同标签 → 关联
   ↓
6. 生成统计报告
```

## 🎯 上下文感知检索

### 智能加载机制

```
用户输入
    ↓
提取关键词 (记忆/进化/VM/...)
    ↓
多维度检索
    ├── 工作记忆 (实时)
    ├── 短期记忆 (近期)
    └── 长期记忆 (永久)
    ↓
去重排序 (按重要性)
    ↓
加载关联记忆
    ↓
格式化为上下文
```

### 示例场景

**场景1: 用户说"优化记忆系统"**
- 自动加载: 记忆系统设计文档、过往优化记录、相关决策

**场景2: 用户说"检查VM状态"**
- 自动加载: VM配置信息、历史状态、故障记录

**场景3: 用户说"开始进化"**
- 自动加载: 进化时间表、过往进化成果、当前系统状态

## 🛠️ 核心组件

### 1. 分层记忆核心 (`layered_memory.py`)

```python
LayeredMemorySystem
├── add_to_working_memory()     # 添加到工作记忆
├── archive_to_short_term()     # 归档到短期
├── archive_to_long_term()      # 归档到长期
├── search_long_term()          # 长期记忆搜索
├── add_association()           # 添加关联
├── consolidate_daily()         # 整理daily文件
└── context_aware_retrieval()   # 上下文感知检索
```

### 2. 自动整理引擎 (`auto_consolidate.py`)

- `consolidate_daily_files()`: 整理daily文件
- `archive_old_short_term()`: 归档旧短期记忆
- `build_memory_associations()`: 构建关联图谱
- `generate_memory_summary()`: 生成统计报告

### 3. 上下文加载器 (`context_loader.py`)

- `extract_keywords()`: 提取关键词
- `load_relevant_memories()`: 加载相关记忆
- `get_memory_for_prompt()`: 为prompt准备记忆

## 🚀 使用方式

### 在对话中自动使用

系统现在会自动根据用户输入加载相关记忆，无需手动调用。

### 手动检索记忆

```python
from scripts.memory-system.layered_memory import get_memory_system

ms = get_memory_system()
results = ms.context_aware_retrieval("关键词")
```

### 手动整理记忆

```bash
python3 scripts/memory-system/auto_consolidate.py
```
