# 用户回复偏好更新 - 2026-02-09

**时间**: 08:24  
**来源**: 飞书消息

## 新增偏好

### 精简回复 v3.0

**原则**: 只输出最终结果，过程信息静默

**执行规则**:
- ❌ 不再发送 "执行中..." / "正在检查..." 等过程消息
- ❌ 不再分多条逐步汇报
- ✅ 只发送一条最终结果消息
- ⚠️ 例外：需要用户确认的关键节点（高风险操作、决策点）

**目的**: 节省token消耗，减少信息噪音

**示例**:
```
用户: 执行某任务

之前:
[消息1] 正在执行...
[消息2] 进度50%...
[消息3] 检查中...
[消息4] ✅ 完成，结果是xxx

之后:
[消息1] ✅ 完成，结果是xxx
```
