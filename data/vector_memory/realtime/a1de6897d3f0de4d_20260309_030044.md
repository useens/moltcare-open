## 自主进化流程 v1.1 - 新增技能本地化评估

### 技能发现 → 评估 → 决策流程

**触发条件**: 发现新技能（ClawHub/GitHub/社区）

**评估标准**:

| 维度 | 评估项 | 权重 | 阈值 |
|------|--------|------|------|
| **功能价值** | 是否解决痛点 | 30% | >7分 |
| **本地化可能** | 能否零token运行 | 25% | 优先考虑 |
| **资源消耗** | 内存/磁盘/CPU | 25% | 看当前资源 |
| **安全风险** | 审计结果 | 20% | 必须🟢或🟡 |

**决策矩阵**:

```
高价值 + 可本地化 + 资源充足 + 安全 → ✅ 立即安装
高价值 + 需API + 资源充足 + 安全 → ⚖️ 评估必要性
高价值 + 可本地化 + 资源不足 + 安全 → 📅 资源释放后安装
低价值 + 任何 → 🚫 暂缓
高风险 → 🔴 永不安装（除非用户特批）
```

**资源评估公式**:
```
可用内存 > 技能需求 × 1.5 → 可安装
可用磁盘 > 技能需求 × 2 → 可安装
当前负载 < 70% → 可安装
```

**自主执行权限**:
- ✅ 可本地化的技能：自主安装，事后汇报
- ⚖️ 需API的技能：记录到pending，等待用户明确需求
- 🚫 资源不足：自动加入资源监控队列，满足条件后自动安装
