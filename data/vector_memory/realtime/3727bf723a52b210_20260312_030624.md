4. skill 源码强制审计

### ClawHub Skill 安全规则
| 风险等级 | 处理方式 |
|----------|----------|
| 🔴 高风险 | 直接拒绝安装（除非用户明确要求并知情） |
| 🟡 中风险 | 详细检查源码，记录风险点，向用户说明后等待确认 |
| 🟢 低风险 | 正常源码审计流程通过后可安装 |

**高风险指标：**
- 需要下载外部二进制文件
- 读取 ~/.env、~/.ssh、~/.aws 等敏感路径
- 发送数据到非官方 API
- 执行网络请求到可疑域名
- 作者信誉未知或为新账号
- 功能描述模糊或过于诱人（"免费API"、"破解版"）

### 安装前强制检查清单
