**5大常见错误**:

1. **Ignoring Audit Trails (忽略审计日志)**
   - 失败: 不记录变更内容
   - 修复: 始终记录构建内容和原因

2. **Not Holding to Reversible Changes (不可逆变更)**
   - 失败: 无法轻松回退的变更
   - 修复: 使用版本控制确保可撤销

3. **Shipping Without Human Review (无人审核即发布)**
   - 失败: 未通知人类的变更
   - 修复: 建立信任关系，即使小变更也要通知

4. **Lack of User Feedback Integration (缺少用户反馈整合)**
   - 失败: 不根据用户反馈调整
   - 修复: 确保融入人类真实需求

5. **Randomizing Changes (随机变更)**
   - 失败: 每次构建塞满许多变更
   - 修复: 每次构建有明确目标，追踪性能目标
