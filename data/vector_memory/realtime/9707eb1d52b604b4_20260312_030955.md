### 1. Moltis - Rust原生AI助手

**项目信息**:
- **GitHub**: https://github.com/moltis-org/moltis
- **描述**: A personal AI gateway written in Rust. One binary, no runtime, no npm.
- **定位**: OpenClaw直接竞品，Rust原生实现

**核心架构**:
```
Moltis架构
├── Single Binary: 单二进制文件，无需运行时
├── Multi-provider LLM: OpenAI Codex, GitHub Copilot, Local LLM
├── Session Persistence: SQLite-backed对话历史
├── Sandboxed Execution: Docker/Apple Container隔离
├── MCP Support: stdio/HTTP/SSE模式
├── Hook System: 生命周期钩子，可拦截/修改/阻止操作
├── Web Gateway: HTTP + WebSocket + 内置Web UI
└── Telegram Integration: 可扩展通道抽象
```

**关键技术特点**:
1. **零配置启动**: `moltis` 默认运行gateway，无需子命令
2. **自动TLS**: 首次运行生成自签名证书
3. **随机端口**: 每次安装选择唯一端口避免冲突
4. **Agent级超时**: 可配置wall-clock timeout(默认600s)
5. **子Agent委托**: `spawn_agent`工具支持嵌套深度限制
6. **并行工具执行**: 单次请求多工具并发执行
7. **内存管理**: 95% token使用率自动压缩session
8. **安全模型**: SSRF保护、秘密处理、WebSocket Origin验证

**与OpenClaw对比**:
| 维度 | Moltis | OpenClaw |
|------|--------|----------|
| 语言 | Rust | TypeScript/Go |
| 二进制 | 单文件 | 多组件 |
| 运行时 | 无 | Node.js/Go |
| 沙箱 | Docker/Apple | Docker |
| MCP | 支持 | 支持 |
| Hooks | 完整系统 | 部分支持 |
| 部署 | Fly.io/DO/Render | 多平台 |

**对森森的启示**:
1. **Rust优势**: 单二进制+零依赖部署体验确实优于Node.js
2. **Hook系统**: 生命周期钩子是可编程策略层的关键
3. **安全边界**: SSRF防护和秘密处理值得借鉴
4. **自动TLS**: 自签名证书生成简化本地HTTPS
5. **竞争压力**: 需要评估Rust重写或混合架构的可行性

### 4. Engram - AI Agent持久化内存层

**项目信息**:
- **GitHub**: https://github.com/EvolvingLMMs-Lab/engram
- **描述**: Privacy-first AI memory layer - Signal for AI Memory
- **标语**: Biological memory fades. Digital memory leaks. We fixed both.

**核心设计**:
```
Engram架构
├── E2E Encryption: AES-256-GCM
├── Local by Default: 数据本地存储，无云服务
├── Zero-Knowledge Sync: 客户端加密，服务端只见密文
├── Semantic Memory: 向量相似度搜索
├── Secrets Vault: API密钥加密存储
├── MCP Native: 原生MCP支持
└── Open Source: 可审计、可自托管
```

**安全机制**:
| 层级 | 算法 |
|------|------|
| At Rest | AES-256-GCM |
| Key Derivation | PBKDF2-SHA256 (600k iterations) |
| Search Index | HMAC-SHA256 (blind indexing) |
| Recovery | BIP39 Mnemonic (24 words) |

**与云记忆对比**:
| 维度 | Engram | Cloud Memory |
|------|--------|--------------|
| 数据位置 | 用户设备 | 服务商服务器 |
| 密钥持有者 | 用户 | 服务商 |
| 是否可读 | 否 | 是 |
| 可验证性 | 是(开源) | 否 |
| 跨应用 | 任何MCP客户端 | 锁定单一应用 |

**Claude Code Agent Teams集成**:
```json
{
  "hooks": {
    "TaskCompleted": ["engram consolidate"],
    "TeammateIdle": ["engram consolidate"]
  }
}
```

**对森森的启示**:
1. **隐私优先**: 本地存储+加密是Agent记忆的未来
2. **MCP集成**: 记忆层作为MCP服务器的架构模式
3. **团队记忆**: Agent Teams的自动consolidation机制
4. **加密搜索**: Blind indexing实现密文搜索
5. **竞争分析**: 需要评估本地加密记忆的实现成本
