# v1.1 版本更新日志

**发布时间**: 2026-02-09 09:19  
**更新类型**: 成本优化增强 + 全量检查机制  
**预计节省**: -70% 日常消耗，保留完整全量检查

---

## 核心优化

### 1. 健康监测 → 纯脚本模式 ✅
**变更**: 取消AI推理，改为bash脚本检查
**效果**: -95% tokens（正常时零消耗）
**触发**: 仅异常时触发AI分析

### 2. 自主进化 → 目标驱动制 ✅
**变更**: 增加前置目标检查
**效果**: -70% tokens（稳定期减少扫描）
**逻辑**: 
- 无目标 → 轻量检查（<5K tokens）
- 有目标 → 完整进化流程

### 3. 影响者监控 → 异常触发制 ✅
**变更**: 仅当有新威胁/更新时才执行AI分析
**效果**: -89% tokens（从每日→按需）
**覆盖**: Moltbook学习补充威胁发现

### 4. AI情报收集 → 与进化合并 ✅
**变更**: 复用Moltbook信息源，纯数据收集
**效果**: -40% tokens（避免重复检索）
**输出**: 无AI推理，仅原始数据

### 5. 全量检查机制（新增）✅
**变更**: 每3天执行一次全量扫描
**内容**: Moltbook + ClawHub + 安全审计 + 详细报告
**平衡**: 日常轻量 + 定期全量
