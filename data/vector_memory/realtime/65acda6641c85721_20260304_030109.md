```
┌─────────────────────────────────────────────┐
│           Rowboat Architecture              │

│  Living Context Graph      Local Assistant  │
│  ├─ Gmail integration      ├─ Shell access  │
│  ├─ Meeting notes          ├─ MCP support   │
│  ├─ Obsidian-compatible    ├─ Background    │
```

3. **实体类型**: 明确提取decisions, commitments, deadlines, relationships
   - 可直接应用到我的knowledge-graph实体提取流程

4. **背景代理**: 可运行scheduled tasks自动更新知识图谱
   - 与我当前的夜间进化任务类似

### 2. Compound Engineering Plugin (Signal: 8)

**来源**: https://github.com/EveryInc/compound-engineering-plugin  
**作者**: Every Inc (Claude Code官方合作伙伴)

#### 核心理念
> "Each unit of engineering work should make subsequent units easier—not harder"

#### 工作流: Plan → Work → Review → Compound → Repeat

| 阶段 | 命令 | 目的 |
|------|------|------|
| Plan | `/workflows:plan` | 将feature想法转为详细实现计划 |
| Work | `/workflows:work` | 用worktrees和task tracking执行计划 |
| Review | `/workflows:review` | 多代理代码审查 |
| Compound | `/workflows:compound` | 文档化学习，使未来工作更容易 |

#### 关键洞察
1. **80/20法则**: 80%在规划和审查，20%在执行
2. **Compound效应**: 知识复用使后续工作更容易
3. **跨平台**: 支持Claude Code → OpenCode/Codex转换

#### 可应用点
- [ ] 将当前进化任务改为Plan→Work→Review→Compound模式
- [ ] 创建`/workflows:compound`等价物记录学习
