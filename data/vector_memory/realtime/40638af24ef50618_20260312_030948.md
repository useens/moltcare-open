## 🧠 技术洞察

### FastMCP API 变更 (v2→v3)

**问题**: FastMCP() 不再接受 `host`, `port`, `log_level` 参数

**旧代码** (报错):
```python
mcp = FastMCP(name="xxx", host="127.0.0.1", port=8000, log_level="info")
mcp.run(transport="streamable-http")
```

**新代码** (修复):
```python
mcp = FastMCP(name="xxx")  # 仅保留 name
asyncio.run(mcp.run_http_async(host="127.0.0.1", port=8000))
```

**应用场景**: Boss直聘 MCP 服务修复

### ARM64 Docker 镜像构建

**问题**: 小红书官方 Docker 镜像是 AMD64，ARM64 服务器无法运行

**解决**: 从 Dockerfile.arm64 本地构建
```bash
cd ~/.agent-reach/tools/xiaohongshu-mcp
docker build -f Dockerfile.arm64 -t xiaohongshu-mcp:local .
docker run -d --name xiaohongshu-mcp -p 18060:18060 xiaohongshu-mcp:local
```

### Scrapling 反检测原理

**多层防护**:
1. **请求层**: Google Referer, 真实 User-Agent, TLS/HTTP/3 指纹
2. **浏览器层**: Playwright 指纹清理, headless 检测绕过
3. **渲染层**: Canvas noise, WebRTC 保护, 时区匹配
4. **挑战层**: 自动解决 Cloudflare Turnstile/JS/Interactive challenges

**关键类**:
- `Fetcher`: 快速 HTTP (TLS 指纹)
- `DynamicFetcher`: 动态内容 (Playwright)
- `StealthyFetcher`: 反检测模式 (全部保护)
