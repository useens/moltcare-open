# 森森系统受保护功能清单

> 🛡️ **PROTECTED LIST** | 精简过程中**绝对不可删除或修改**的功能  
> **原则**: 即使系统精简到只剩核心，这些功能也必须保留

---

## 一级保护 (核心生存功能)

### 1. GitHub备份同步系统

**保护等级**: 🔴 **绝对不可精简**

**关键组件**:
```
scripts/backup/
├── github-backup.sh              # 核心备份脚本
├── conditional-git-sync.sh       # 条件同步
└── forced-git-sync.sh           # 强制同步

# 或者统一后的:
scripts/backup/git-backup.sh      # 统一备份入口
```

**保护原因**:
- 这是森森的数据生命线
- 所有记忆、配置、脚本都依赖GitHub备份
- 一旦失效，系统可能无法恢复

**允许操作**:
- ✅ 合并多个备份脚本为统一脚本
- ✅ 优化备份逻辑
- ✅ 改进备份策略

**禁止操作**:
- ❌ 删除备份功能
- ❌ 修改备份目标 (必须推送到GitHub)
- ❌ 减少备份频率到危险水平

---

### 2. 核心记忆系统

**保护等级**: 🔴 **绝对不可精简**

**关键组件**:
```
MEMORY.md                         # 核心长期记忆
memory/                           # 记忆存储目录
├── YYYY-MM-DD.md                # 每日记忆
├── archive/                     # 归档记忆
└── associations/                # 知识关联

# 向量记忆系统
data/vector_memory/              # 向量记忆存储
scripts/memory-system/           # 记忆管理脚本
```

**保护原因**:
- 这是森森的知识基础
- 记录用户偏好、历史交互、学习成果
- 失去记忆 = 失去用户上下文

**允许操作**:
- ✅ 优化记忆存储格式
- ✅ 合并重复的记忆文件
- ✅ 压缩旧记忆归档

**禁止操作**:
- ❌ 删除MEMORY.md
- ❌ 清空memory/目录
- ❌ 禁用向量记忆系统
- ❌ 删除历史每日记忆

## 精简操作检查清单

在精简任何功能前，必须确认:

- [ ] 该功能不在上述受保护清单中
- [ ] 已检查是否被其他受保护功能依赖
- [ ] 已备份到.trash目录 (保留30天)
- [ ] 已在测试环境验证无影响
- [ ] 已记录变更原因

---

## 紧急情况处理

如果发现误删了受保护功能:

### 1. 立即停止所有精简操作
```bash
touch /root/.openclaw/workspace/.emergency-stop
```

### 2. 从备份恢复
```bash
cd /root/.openclaw/workspace
git checkout HEAD -- [被删除的文件]
```

### 3. 验证恢复
```bash
ls -la [被删除的文件路径]
```

### 4. 通知用户
记录事件并评估影响。
