### SQL替代向量DB for Agent记忆

**HN表现**: 136 points, 63 comments  
**核心观点**: 关系型数据库比向量DB更适合Agent记忆

**对比分析**:

| 方案 | 优点 | 缺点 |
|------|------|------|
| Prompt stuffing | 简单 | Token爆炸，成本高昂 |
| Vector DB (RAG) | 语义召回 | 检索噪声大，丢失结构 |
| Graph DB | 关系推理强 | 难扩展和维护 |
| **Relational DB** | **结构化、Join/Index、50年验证** | **需要 schema 设计** |

**实现方式**:
- Short-term vs Long-term memory in SQL tables
- 实体/规则/偏好作为结构化记录
- 重要事实提升为永久记忆
- Join和Index优化检索
