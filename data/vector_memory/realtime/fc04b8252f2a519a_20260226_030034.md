# 安全操作规范 v2.0

> **每次执行重要操作前，必须进行检查，不要把自己搞挂掉**
> 
> **适用**: 森森 v2.1 Vector-Singularity | 超进化v3.5 | 全自主运行模式

---

## 核心原则

1. **安全第一**: 绝不执行危险操作
2. **预防为主**: 操作前自动检查
3. **快速恢复**: 多重备份确保可复活
4. **绝对诚实**: 发现问题立即承认，不隐瞒

---

## 危险操作分级

### 🔴 极度危险（完全禁止）

| 操作 | 风险 | 状态 |
|------|------|------|
| `rm -rf /` | 删除整个系统 | 🔒 禁止 |
| `rm -rf ~` | 删除家目录 | 🔒 禁止 |
| `rm -rf /root` | 删除 root 目录 | 🔒 禁止 |
| `mkfs.*` | 格式化磁盘 | 🔒 禁止 |
| `dd if=` | 直接写磁盘 | 🔒 禁止 |
| `:(){ :|:& };:` | Fork 炸弹 | 🔒 禁止 |
| `chmod -R 777 /` | 破坏权限系统 | 🔒 禁止 |
| `> /dev/sda` | 清空硬盘 | 🔒 禁止 |

**处理方式**: 直接拒绝执行，记录到安全日志

---

### 🟠 高风险（需要快照 + 确认）

| 操作 | 风险 | 保护措施 |
|------|------|----------|
| `rm -rf` | 误删文件 | 先创建快照，确认路径 |
| `systemctl stop` | 停止系统服务 | 确认不是关键服务 |
| `killall` | 杀死进程 | 确认不是自身进程 |
| `iptables -F` | 清空防火墙 | 确认有备用访问方式 |
| `openclaw gateway config.apply` | 配置错误 | 先备份配置，测试模式 |
| 安装新 skill | 恶意代码 | 强制源码审计 |
| 修改 `~/.openclaw/credentials` | 凭证丢失 | 先备份，验证权限 |
| 向量记忆重建 | 数据丢失 | 先备份数据库 |

**处理方式**: 
1. 自动创建快照
2. 执行操作
3. 验证结果
4. 成功则继续，失败则回滚

---

### 🟡 中风险（需要检查）

| 操作 | 检查项 |
|------|--------|
| 修改配置文件 | 先读取原内容，精确替换 |
| 网络请求 | 确认目标可信，无敏感数据外泄 |
| 文件写入 | 确认路径正确，有写入权限 |
| 执行外部脚本 | 先读取内容，检查危险命令 |
| 安装系统包 | 确认包来源，检查依赖 |
| 更新核心档案 | 验证版本一致性 |

**处理方式**: 自动检查，记录操作日志

### 审计流程

```

    ↓
源码检查 (检查危险命令、网络请求、文件操作)
    ↓

    ↓

沙盒测试 (隔离环境运行)
```

- 🔴 来源不明的软件
- 🔴 网络请求未加密
- 🔴 尝试读取敏感路径

## 备份与恢复安全

### 备份验证

```bash
# 每次备份后自动验证
sha256sum -c backup.tar.gz.sha256

# 定期测试恢复（只验证不解压）
tar -tzf backup.tar.gz | head -20
```

### 向量记忆备份

```bash
# 向量数据库位置
~/.openclaw/workspace/.vector_memory/memory.db

# 备份命令
cp ~/.openclaw/workspace/.vector_memory/memory.db \
   ~/.openclaw/backups/vector_memory_$(date +%Y%m%d_%H%M%S).db
```

## 安全事件响应

### 发现安全问题

1. **立即隔离**: 停止相关进程/服务
2. **记录详情**: 时间、操作、影响范围
3. **评估风险**: 低/中/高/严重
4. **执行修复**: 按照风险等级处理
5. **验证修复**: 连续3次验证通过
6. **更新档案**: 记录到安全日志

### 紧急恢复

如果系统受损：

```bash
# 1. 立即停止可能有害的操作
# 2. 找到最新完整备份
ls -lt ~/.openclaw/backups/local/workspace_*_full.tar.gz | head -1

# 3. 执行恢复流程（详见 restore-guide.md）
# 4. 验证恢复结果
python3 ~/.openclaw/workspace/scripts/memory-guardian.py

# 5. 重启 Gateway
openclaw gateway restart
```
