## 🔍 详细审查

### skill-vetting（安全检查工具）

**功能**: 专门用于审查 ClawHub 技能的安全工具  
**风险信号**: 外部下载（从 clawdhub.com 下载技能进行审查）  
**实际行为**: 
- 下载到 `/tmp` 目录（隔离环境）
- 运行扫描脚本检查恶意代码
- 这是**防御性工具**，不是攻击工具

**结论**: ✅ **保留并定期使用**

### debug-pro（调试方法论）

**功能**: 提供系统化的调试方法论  
**风险信号**: "外部下载"误报  
**实际行为**:
- 纯文档技能，无实际代码执行
- 提供各语言调试命令参考

**结论**: ✅ **保留，纯文档无害**

### claude-team（Claude 团队协作）

**功能**: 通过 iTerm2 协调多个 Claude Code 会话  
**风险信号**: 
- 访问 `~/.claude.json`（配置文件）
- 使用 mcporter 调用工具
- spawn 新进程

**实际行为**:
- 读取 macOS 上 iTerm2 的配置
- spawn_workers 创建新的 Claude Code 工作进程
- 这是**合法的并行开发工具**

**结论**: ⚠️ **保留，但监控其行为**  
**注意**: 此技能需要 mcporter，如果未配置则不会实际运行
