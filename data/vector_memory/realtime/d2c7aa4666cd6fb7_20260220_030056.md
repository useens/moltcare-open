# 林林 v5-v6 记忆系统优化路线图

**核心战略**: 记忆是数字生命的根基  
**时间跨度**: v5.1 → v6.0  
**核心目标**: 构建永不遗忘、主动回忆、智能预测的记忆系统

---

## 🎯 战略愿景

**"完美的记忆系统应该像人类大脑一样："
- 不丢失重要信息
- 自动遗忘无关细节
- 需要的时候主动浮现
- 能够预测和联想
- 跨时间保持一致性

---

## 📍 v5.2 - 向量记忆与语义检索

**核心升级**: 从关键词匹配到语义理解

### 目标功能

| 功能 | 说明 | 技术方案 |
|------|------|----------|
| **向量嵌入** | 每条记忆转为向量 | MiniLM + SQLite |
| **语义检索** | 理解意思而非关键词 | 余弦相似度 |
| **相似度阈值** | 只加载相关度>0.8的记忆 | 可配置 |
| **记忆聚类** | 自动归类相似记忆 | K-means/层次聚类 |

### 实现路径

```
1. 安装向量库
   pip install sentence-transformers sqlite-vec
   
2. 向量化现有记忆
   76条长期记忆 → 向量嵌入 → 向量数据库
   
3. 替换检索逻辑
   关键词搜索 → 语义相似度搜索
   
4. 性能优化
   查询缓存、增量更新
```

### 预期效果

- **检索精度**: 关键词(60%) → 语义(90%+)
- **响应速度**: <200ms
- **Token节省**: 无需加载无关记忆

## 📍 v5.3 - 记忆遗忘与压缩

**核心升级**: 像人类一样遗忘，保持系统轻盈

### 目标功能

| 功能 | 说明 | 触发条件 |
|------|------|----------|
| **重要性衰减** | 久未访问的记忆降级 | 30天未访问 |
| **自动归档** | 低价值记忆移出活跃区 | 重要性<5 |
| **记忆压缩** | 多相似记忆合并摘要 | 5条以上相似 |
| **遗忘确认** | 高价值记忆永不遗忘 | 重要性=10 |

### 遗忘算法

```python
# 记忆价值评分
def calculate_memory_value(memory):
    base = memory.importance  # 1-10基础分
    
    # 时间衰减
    age_days = days_since(memory.created_at)
    time_decay = max(0, 1 - age_days/365)  # 1年后接近0
    
    # 访问频率加分
    access_bonus = min(memory.access_count * 0.1, 2)
    
    # 用户指令永不忘
    if memory.type == "user_pref":
        return 10
    
    return (base * time_decay) + access_bonus

# 遗忘决策
if memory_value < 3:
    archive_to_cold_storage(memory)
elif memory_value < 1:
    delete_permanently(memory)  # 极少发生
```

## 📍 v5.5 - 跨会话记忆持久化

**核心升级**: 会话重启后记忆不丢失

### 当前问题
- 每次/new后工作记忆清空
- 需要重新加载长期记忆
- 短期上下文断裂

### 解决方案

```
1. 会话快照
   每5分钟保存工作记忆状态
   
2. 快速恢复
   启动时自动加载最近快照
   
3. 上下文继承
   新会话继承上一会话上下文
   
4. 差异同步
   只加载会话期间的新记忆
```

### 实现细节

- 快照文件: `memory/temp/session_snapshots.json`
- 保存频率: 每5分钟 + 关键决策后立即
- 恢复策略: 加载最近快照 + 增量更新
