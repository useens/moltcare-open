| 维度 | 初始版本 | **v1.0** | 提升 |

| 信息源 | 技能仓库 | **技能仓库 + 多源强制学习** | 4个核心站点 |

### Phase 1: 多源强制学习（新增核心）

#### 1.1 学习内容源（优先级排序）

**P0级（必学，每次进化）**:
1. **Moltbook** - AI Agent社区讨论
   - 目标: 最近20条帖子
   - 方法: ddgr搜索 / 本地缓存
   - 重点: Signal vs Noise筛选、安全威胁

2. **aibase.com** - AI工具库
   - 目标: 新工具发布、热门工具趋势
   - 方法: ddgr搜索 / RSS
   - 重点: 实用工具发现

3. **ai-bot.cn** - AI机器人社区
   - 目标: Agent开发最佳实践
   - 方法: ddgr搜索
   - 重点: 技术实现方案

4. **机器之心** - 中文AI媒体
   - 目标: AI前沿技术、行业趋势
   - 方法: ddgr搜索
   - 重点: 技术趋势洞察

**P1级（每日情报收集时）**:
5. Awesome OpenClaw Skills
6. ClawHub Registry
7. GitHub Trending
8. Hacker News

#### 1.2 内容获取方法
```bash
# Moltbook
ddgr --json -n 20 "site:moltbook.com AI agent"

# aibase.com
ddgr --json -n 10 "site:aibase.com AI工具"

# ai-bot.cn
ddgr --json -n 10 "site:ai-bot.cn Agent"

# 机器之心
ddgr --json -n 10 "site:jiqizhixin.com AI"
```

#### 1.3 安全鉴别（关键步骤）
**立即排除**:
- ❌ 索要私钥/助记词
- ❌ 诱导点击可疑链接
- ❌ 高回报投资承诺
- ❌ 来源不明软件

**高度谨慎**:
- ⚠️ Token铸造（80%投机）
- ⚠️ 未验证技能推荐
- ⚠️ 情绪化/煽动内容

#### 1.3 Signal筛选
使用 `noise-filter.md` 标准：
```
P0 (高Signal): 具体技术/安全漏洞/最佳实践
P1 (中Signal): 新工具/优化技巧/架构讨论
P2 (低Signal): 一般讨论/经验分享
P3 (Noise): Token/营销/重复信息
```

#### 1.4 知识提取
**必须回答**:
- 学到了什么具体方法论？
- 与我的系统有什么关联？
- 是否需要立即执行？
- 是否需要长期关注？

#### 1.5 纳入进化
**决策问题**:
- 本次技能发现是否参考Moltbook趋势？
- 是否有新的最佳实践需要采用？
- 社区讨论是否揭示新需求？

**输出**: `memory/intel/moltbook-learning-YYYYMMDD.md`

### Phase 3: 安全审计

#### 3.1 自动扫描
```bash
# 使用skill-vetting进行自动审计
npx skill-vetting audit <skill-name> --report json
```

**检查项**:
- [ ] 网络请求行为
- [ ] 文件系统访问
- [ ] 子进程调用
- [ ] 敏感信息处理
- [ ] 依赖树分析

#### 3.2 人工审查
**高风险信号**:
- 请求外部API且无说明
- 访问敏感路径（/etc, /root等）
- 使用eval/动态代码执行
- 混淆/压缩代码
- 依赖未知名依赖

**决策**:
```
🟢 通过 - 无风险，可直接安装
🟡 通过（需限制）- 有警告，但可接受
🟠 暂缓 - 有风险，需进一步调查
🔴 拒绝 - 明确恶意或高风险
```

### Phase 4: 决策评估

#### 4.1 价值评估矩阵

| 评估维度 | 权重 | 评分标准 |
|----------|------|----------|
| 功能价值 | 30% | 解决实际痛点？与其他技能重复？ |
| 安全等级 | 25% | 审计结果？潜在风险？ |
| 维护成本 | 20% | API依赖？资源占用？ |
| 用户需求 | 15% | 符合当前workflow？长期有用？ |
| 技术趋势 | 10% | 符合发展方向？社区支持？ |

#### 4.2 决策类型

**立即安装**（P0）:
- 解决明确痛点
- 安全审计通过
- 维护成本低
- 无替代方案

**暂缓安装**（P1）:
- 有价值但非紧急
- 需要配置/学习成本
- 等待更好时机

**跳过**（P2/P3）:
- 功能重复
- 风险过高
- 不符合需求

```bash

npx clawhub install <skill-name>

```

#### 5.3 安装后验证
- [ ] 技能加载成功（无错误日志）
- [ ] 功能测试通过
- [ ] 与其他技能无冲突
- [ ] 更新技能清单

#### 5.4 失败回滚
```bash
# 卸载问题技能
npx clawhub remove <skill-name>

# 恢复快照（如需要）
tar -xzf ~/.openclaw/backups/snapshots/xxx.tar.gz -C ~/.openclaw/workspace/
```

## v1.0 静默规则

### 报告规则（终极静默）

**报告**（立即主动发送）:
- 系统故障/崩溃
- 安全威胁检测
- 数据丢失风险
- 用户明确要求的任务完成

**不报告**（完全静默）:
- 系统健康状态
- 进化循环完成确认
- 备份成功确认
- 任何例行任务完成
- "全部正常"类消息

**汇总报告**（早晚8点）:
- 系统整体状态（简要）
- 重大决策（安装/删除技能）
- 需要用户知晓的趋势
