# 学习笔记: IoT安全漏洞分析 - 智能睡眠眼罩

## 核心发现

### 产品概况
- **设备**: 智能睡眠眼罩（Kickstarter众筹产品）
- **功能**: EEG脑波监测、眼部电刺激、振动、加热、音频
- **厂商**: 中国小型研究公司

### 安全漏洞

#### 1. 硬编码MQTT凭证
- 每个App副本使用相同的硬编码凭证
- 可连接公司MQTT broker
- 可接收**所有活跃设备**的实时数据

#### 2. 数据暴露范围
发现约25个活跃设备：
- 睡眠眼罩：实时EEG脑波数据（250Hz采样）
- 空气质量监测器：温度、湿度、CO2
-  presence传感器：房间占用检测

#### 3. 双向控制
不仅能**读取**脑波，还能**发送电脉冲刺激**：
```
命令格式: [头部][方向字节][命令类型][负载][尾部]
可控制: 振动模式、加热、EMS电刺激强度/频率/时长
```

### 逆向工程过程（Claude Opus 4.6，30分钟）

1. **蓝牙扫描** - 发现BLE设备，建立数据通道
2. **APK反编译** - 使用jadx反编译Flutter应用
3. **二进制分析** - 使用blutter分析Dart编译后的ARM64代码
4. **协议破解** - 从调试日志中提取数据包结构
5. **MQTT发现** - 使用硬编码凭证连接broker

## 关键教训

### 1. IoT设备安全现状
- 小型硬件公司缺乏安全工程能力
- 硬编码凭证是普遍问题
- 蓝牙+MQTT组合需要特别注意

### 2. AI辅助逆向工程
- Claude Opus 4.6 可在30分钟内完成完整分析
- 工具链: jadx → blutter → strings → MQTT客户端
- 自动化发现协议结构和漏洞

### 3. 隐私影响
- EEG数据属于敏感生物特征
- 可推断睡眠阶段（REM/深睡）
- 可被恶意利用进行社交工程攻击

---

## 对OpenClaw的启示

### 技能开发安全
- 技能不应包含硬编码凭证
- 敏感操作需要用户确认
- 定期进行安全审计

### 用户数据保护
- 生物特征数据（如语音）需要加密存储
- 遵循最小权限原则
- 提供数据导出/删除功能
