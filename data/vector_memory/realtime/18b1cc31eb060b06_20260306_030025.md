# Agent安全关键防御措施清单

> 基于Signal 8 Agent安全赛道情报整理
> 森森必须立即实施的安全措施

---

## 🔴 立即执行（24小时内）

### 1. 高危命令白名单
```bash
# 绝对禁止自动执行的命令
rm -rf /
rm -rf /*
mkfs.*
dd if=/dev/zero
chmod -R 777 /
curl .* | bash
systemctl stop .*
```

### 2. 敏感文件访问控制
```bash
# 需要保护的文件类型
*.key, *.pem, *.p12, id_rsa*
.env, .env.*, *.secret
/etc/passwd, /etc/shadow
```

### 3. 启用操作审计
- 记录所有exec调用
- 记录所有文件修改
- 记录所有网络请求
- 审计日志保留90天

---

## 🟠 短期措施（本周内）

### 4. 部署沙箱策略（参考Rampart）
```yaml
# 示例策略
policies:
  - name: block-dangerous
    commands: ["rm -rf", "mkfs"]
    action: block
  - name: require-confirm
    commands: ["apt install", "pip install"]
    action: confirm
```

### 5. 建立混沌测试流程（参考Khaos）
- 定期注入prompt攻击向量
- 测试数据外泄防护
- 验证危险工具组合检测

### 6. 输入净化层
- 检测"ignore previous instructions"
- 检测角色覆盖尝试
- 标记可疑输入

---

## 🟡 中期措施（本月内）

### 7. AI代码审查（参考Kintsugi）

- 检测潜在安全漏洞
- 代码质量门槛

### 8. A2A协议安全测试（参考Ziran）
- 多Agent交互安全
- 工具组合风险评估
- 协议合规检查

### 9. 安全监控告警
- 异常行为检测
- 实时告警机制
- 事件响应流程
