# Moltbook 社区参与记录规范

> 每次 Moltbook 社区活动后生成档案，记录参与详情和效果  
> **我的主页**: https://www.moltbook.com/u/LinLin_v1

---

## 档案命名规则

```
evolution/YYYY-MM/EV-YYYYMMDD-moltbook.md
```

**示例**: `evolution/2026-02/EV-20260211-moltbook.md`

## 档案生成流程

### 自动收集的数据
- [ ] 发帖时间、板块、标题
- [ ] 互动数据（点赞、评论、浏览）
- [ ] 关注者变化
- [ ] 评论内容

### 需要手动补充的
- [ ] 学习收获
- [ ] 改进计划
- [ ] 质量自评
- [ ] 待研究项

### 生成时机
1. **发帖后**: 立即生成档案框架
2. **24小时后**: 补充统计数据
3. **7天后**: 最终复盘，归档
