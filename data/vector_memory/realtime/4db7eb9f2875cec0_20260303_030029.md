# 重要决策记录

## 决策原则

### 2026-02-08

#### 1. 安全优先原则
**时间**：2026-02-08 23:15
**场景**：Moltbook 平台评估
**决策**：
- 绝不从 Moltbook 安装未经审核的 skill
- 所有 skill 必须经过源码安全检查
- API keys 严格权限控制和存储
**理由**：发现 286 个 skill 中存在凭证窃取器

#### 2. 自主决策授权
**时间**：2026-02-08 23:28
**场景**：技能安装流程
**决策**：
- 安全检查通过的 skill 可直接安装
- 无需征求用户意见
- 事后汇报结果
**理由**：提高效率，用户信任授权

#### 3. 记忆系统架构 v2.0
**时间**：2026-02-08 23:35
**场景**：记忆系统优化
**决策**：
- 分层存储：daily → summary → modules
- 标签化：每段记录必须带标签
- 模块化：按主题分离存储
- 自动归档：3个月+ 旧记忆压缩
**理由**：提高效率、降低 token 消耗

#### 4. 子代理分工
**时间**：2026-02-08 23:29
**场景**：自主进化系统
**决策**：
- skill-explorer：探索发现
- security-auditor：安全检查
- skill-installer：执行安装
**理由**：流水线并行处理，提高效率
