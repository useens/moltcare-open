## 实体类型定义

### 1. Decision（决策）
**定义**: 用户做出的重要决定或选择
**触发信号**: 
- "我决定..."
- "让我们选择..."
- "确定采用..."
- "放弃/取消..."

**存储格式**:
```markdown
## DECISION-YYYYMMDD-XXX

**时间**: YYYY-MM-DD HH:MM
**上下文**: [对话/任务链接]
**决策内容**: 
**决策原因**: 
**相关实体**: 
**状态**: 已执行/待执行/已变更
```

---

### 2. Commitment（承诺）
**定义**: 我或用户做出的承诺、约定
**触发信号**:
- "我承诺..."
- "我会..."
- "确保..."
- "明天给你..."

**存储格式**:
```markdown
## COMMITMENT-YYYYMMDD-XXX

**时间**: YYYY-MM-DD HH:MM  
**承诺方**: 我/用户  
**承诺内容**: 
**截止时间**: 
**关联对话**: 
**状态**: 待完成/已完成/已取消
```

---

### 3. Deadline（截止日期）
**定义**: 明确的时间限制或截止日期
**触发信号**:
- "在...之前"
- "截止到..."
- "明天/下周/月底"
- "DDL"

**存储格式**:
```markdown
## DEADLINE-YYYYMMDD-XXX

**设定时间**: YYYY-MM-DD HH:MM
**截止时间**: YYYY-MM-DD HH:MM
**事件**: 
**优先级**: P0/P1/P2/P3
**提醒设置**: 
**状态**: 进行中/已到期/已完成
```

---

### 4. Relationship（关系）
**定义**: 用户与外部实体的重要关系
**触发信号**:
- "我的朋友/同事..."
- "和...合作"
- "负责..."
- "隶属于..."

**存储格式**:
```markdown
## RELATIONSHIP-YYYYMMDD-XXX

**主体**: 用户
**关系类型**: 朋友/同事/上下级/合作
**客体**: 
**关系描述**: 
**重要程度**: 高/中/低
**首次识别**: YYYY-MM-DD
```

---

## 提取流程

### 自动提取触发
1. 每次对话结束后，扫描内容
2. 识别上述4类实体的触发信号
3. 生成实体记录草稿
4. 标记为"待确认"

### 人工确认（当前）
1. 每日回顾标记的实体
2. 确认或修正提取内容
3. 归档到本文件

### 与向量记忆关联
```
实体记录 → 包含对话ID/时间戳 → 可检索原始上下文
```
