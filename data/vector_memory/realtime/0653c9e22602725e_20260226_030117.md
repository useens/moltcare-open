## 🚀 快速开始

### 1. 安装精简守护进程
```bash
cd /root/.openclaw/workspace
bash scripts/self-pruning/install-guardian.sh
```

### 2. 启动服务
```bash
systemctl start sensen-pruning.service
systemctl enable sensen-pruning.service
systemctl enable sensen-pruning-l3.timer
```

### 3. 手动执行L2扫描
```bash
python3 scripts/self-pruning/pruning-guardian.py --l2-only
```

### 4. 手动执行L3评估
```bash
python3 scripts/self-pruning/pruning-guardian.py --l3-only
```

### 5. 执行精简 (试运行)
```bash
python3 scripts/self-pruning/executor/l2-pruning-executor.py
```

### 6. 执行精简 (实际)
```bash
python3 scripts/self-pruning/executor/l2-pruning-executor.py --execute
```
