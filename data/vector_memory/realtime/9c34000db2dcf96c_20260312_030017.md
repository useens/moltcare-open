# 2026-03-10 - 守护进程禁用与自动化恢复

## 事件总结

### 失联原因
- **时间**: 2026-03-10 02:00-09:13
- **根本原因**: 智能升级守护进程执行升级后触发系统状态异常
- **触发器**: `/etc/systemd/system/sensen-intelligence-upgrade.service`

### 问题症状
1. 网络连接异常 (ECONNRESET)
2. LLM API 长期无响应 (600秒超时)
3. Cron 任务累积错误
4. 消息传递失败

---

## 修复措施

### 1. 禁用自动升级守护进程

**已禁用服务**:
- `sensen-intelligence-upgrade.service`
- `sensen-self-upgrade.service`
- `sensen-system-pruning.service`
- `hyper-evolution.service`
- `hyper-evolution-engine.service`

**操作**:
```bash
systemctl stop sensen-intelligence-upgrade sensen-self-upgrade sensen-system-pruning hyper-evolution hyper-evolution-engine
systemctl disable sensen-intelligence-upgrade sensen-self-upgrade sensen-system-pruning hyper-evolution hyper-evolution-engine
```

### 2. 恢复 MoltCare 自动化

**已恢复 Cron 任务**:
