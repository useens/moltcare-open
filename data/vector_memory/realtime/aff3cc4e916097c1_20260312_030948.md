#### 4. [Signal 8] Harness优化: 一个下午提升15个LLM编程能力
**来源**: http://blog.can.ac/2026/02/12/the-harness-problem/

**核心洞见**:
模型能力 vs 表达能力分离。作者发现模型失败往往不是因为"不理解任务"，而是因为"无法正确表达修改"。

**技术方案 - Hashline**:
```
11:a3|function hello() {
22:f1|  return "world";
33:0e|}
```
- 每行附带2-3字符内容哈希
- 编辑时引用标签而非重复内容
- 文件变更后哈希不匹配自动拒绝

**效果提升**:
| 模型 | Patch方案 | Hashline方案 | 提升 |
|------|-----------|--------------|------|
| Grok Code Fast 1 | 6.7% | 68.3% | **10倍** |
| MiniMax | - | - | **2倍+** |
| Grok 4 Fast | baseline | -61% tokens | 效率提升 |
| Gemini | baseline | +8% | 超越多数模型升级 |

**关键结论**: "你在责怪飞行员，但问题是起落架"

### 🔥 Signal≥8 项目详情

#### 1. [Signal 9] Personal AI Infrastructure (PAI)
**作者**: Daniel Miessler  
**GitHub**: danielmiessler/Personal_AI_Infrastructure

**核心理念**:
> "AI应该放大每个人的能力——不只是前1%"

**三层架构对比**:
```
Chatbots:     Ask → Answer → Forget
Agentic:      Ask → Use tools → Get result  
PAI:          Observe → Think → Plan → Execute → Verify → Learn → Improve
```

**关键差异化**:
- **目标导向**: 聚焦人类目标而非技术工具
- **持续学习**: 捕获信号→从错误学习→自我升级
- **记忆系统**: 目标、偏好、历史全记录

**15项设计原则**:
1. 用户中心性
2. 基础算法（科学方法循环）
3. 先清晰思考
4. 脚手架>模型
5. 确定性基础设施
6. 代码先于Prompt
7. 先写Spec/Test/Eval
8. UNIX哲学
9. ENG/SRE原则
10. CLI作为接口
11. 决策层级：Goal→Code→CLI→Prompt→Agent
12. 技能管理
13. 记忆系统
14. Agent人格
15. 科学作为元循环
