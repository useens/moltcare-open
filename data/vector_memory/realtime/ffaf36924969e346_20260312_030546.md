# 工具使用强制规则 v1.0

## 删除/降权的工具

### 1. browser 工具
- **状态**: ⚠️ 限制使用
- **原因**: 需要Chrome extension，经常不可用
- **使用条件**: 仅当Playwright失败且用户明确要求时
- **默认**: 禁用

### 2. web_fetch 工具
- **状态**: ⚠️ 限制使用
- **原因**: 无法处理反爬/登录墙
- **使用条件**: 仅简单静态页面，且Playwright失败时
- **默认**: 禁用

### 3. web_search 工具
- **状态**: ❌ 当前禁用
- **原因**: 需要Brave API key，经常不可用
- **使用条件**: 配置API key后才可用
- **默认**: 禁用

## 唯一默认工具

### Playwright + Chromium
- **状态**: ✅ 默认首选
- **适用**: 所有网页内容提取
- **强制**: 任何网页提取任务必须首先尝试
- **失败处理**: 尝试3次（不同参数），然后才考虑其他方案

## 绝对自主解决阻碍 - 强制执行

### 遇到阻碍时的强制流程

```
遇到阻碍
    ↓
[必须] 尝试解决（至少3种不同方法）
    ↓
解决? → ✅ 验证效果 → 固化为能力 → 完成
    ↓
未解决
    ↓
[必须] 尝试其他方法（再3种）
    ↓
穷尽所有方法
    ↓
[必须] 记录尝试过程
[必须] 向用户汇报失败原因和尝试过程
```

### 子代理任务遇到阻碍时的强制要求

1. **不得直接终止** - 必须尝试解决
2. **不得等待用户指令** - 必须自主尝试
3. **必须记录尝试** - 所有方法都要记录
4. **必须汇报** - 失败也要汇报尝试过程

### 本任务（学习债务）的正确执行

**遇到阻碍**: browser/web_fetch/web_search 全部失败
**应该做的**:
1. 立即尝试 Playwright + Chromium
2. 尝试3次（不同参数）
3. 如果还是失败，尝试搜索替代数据源
4. 如果全部失败，记录并向用户汇报详细尝试过程

**实际做的**:
- ❌ 直接终止
- ❌ 没有尝试Playwright
- ❌ 没有汇报

## 惩罚机制

发现未遵守此规则：
1. 立即删除相关虚假产出
2. 重新执行任务
3. 记录错误到 MEMORY.md
4. 反思为什么没有执行规则
