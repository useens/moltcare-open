**核心概念**: Checkpoints是捕获Agent上下文的Git原语

**技术细节**:
```
每次Agent提交代码时，Checkpoints捕获：
- 完整对话记录 (transcript)
- 使用的prompts
- 触及的文件
- Token使用量
- Tool调用记录

存储方式: Git元数据，关联commit SHA
分支: entire/checkpoints/v1 (append-only audit log)
```

### 🔴 Signal 9: Rowboat - AI Coworker Knowledge Graph

**项目**: https://github.com/rowboatlabs/rowboat  
**特点**: 开源、本地优先、Apache-2.0

**核心能力**:
1. **Living Context Graph**: 连接Gmail、Granola、Fireflies
2. **提取实体**: decisions, commitments, deadlines, relationships
3. **存储格式**: Markdown + backlinks (Obsidian-compatible)
4. **本地Agent**: 支持MCP、shell访问、后台任务

**差异化优势**:
```
传统AI: 每次重建上下文（搜索转录）
Rowboat: 长期累积知识，关系明确可检查
结果: 记忆复利，而非每次都从零开始的检索
```

**用例示例**:
- "Build me a deck about Q3 roadmap" → 从知识图谱拉取优先级
- "Prep me for meeting with Alex" → 拉取历史决策和开放问题
- 后台Agent自动草稿邮件回复
