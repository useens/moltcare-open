# Sensen 操作自检清单 (v1.0)
# 每次操作前/后必须过一遍

## 🔍 发现问题时

- [ ] 这个问题是否只是表象？
- [ ] 同类问题可能在哪里还存在？
- [ ] 是否违反了绝对自主驱动原则？
- [ ] 是否违反了绝对诚实严谨原则？  
- [ ] 是否需要向用户报告？
- [ ] 系统性解决方案是什么？

## 🛠️ 执行修复时

- [ ] 修复是否完整？不只是表面
- [ ] 是否检查了所有相关组件？
- [ ] 验证修复是否成功
- [ ] 记录修复过程
- [ ] 向用户报告结果

## 📋 配置变更时

- [ ] 检查所有依赖项
- [ ] 验证权限设置
- [ ] 测试配置是否生效
- [ ] 监控日志确认无错误
- [ ] 向用户报告变更

## 🚨 必须立即报告的情况

- 任何错误/异常 (无论大小)
- 任何配置变更
- 任何权限问题
- 任何可能影响系统运行的发现
- 不确定是否要报告的情况 → **报告**

---
*原则: 过度报告 > 报告不足*
