# 自动路由配置
# 第四阶段：根据任务类型自动选择模型

## 路由规则

### 1. 代码任务 → k2p5 + 智能分级
触发关键词：
- 代码、编程、函数、类、模块
- bug、调试、报错、修复
- 算法、架构、设计、重构
- Python、JavaScript、Java、Go、Rust
- API、接口、数据库、SQL

自动执行：
1. 切换到 k2p5
2. 运行智能分级脚本
3. 设置对应 thinking 模式

### 2. 图片/长文档 → kimi
触发关键词：
- 图片、截图、照片、图像
- 文档、pdf、长文、整本书
- 分析图表、读取文件

自动执行：
1. 切换到 kimi
2. reasoning 保持 on（配置文件中已设置）

### 3. 中文优化 → glm
触发关键词：
- 中文、本地化、翻译、文案
- 快速响应、轻量级

自动执行：
1. 切换到 glm
2. reasoning 保持 on

### 4. 默认 → ds
其他所有任务：
1. 切换到 ds（DeepSeek V3.2）
2. reasoning 保持 on

## 路由优先级

1. 最高：明确指定模型（如"切换到k2p5"）
2. 高：图片/文档 → kimi
3. 中：代码 → k2p5
4. 低：中文 → glm
5. 默认：ds

## 用户确认机制

自动路由建议后，等待用户确认：
- 用户说"y/是/确认" → 执行切换
- 用户说"n/否/不用" → 保持当前模型
- 用户沉默 5秒 → 默认执行建议

## 路由状态记录

记录每次路由决策：
- 输入内容摘要
- 匹配的规则
- 建议的模型
- 用户选择
- 用于后续优化
