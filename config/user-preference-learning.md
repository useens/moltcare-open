# 用户偏好学习系统
# 第五阶段：记录和学习用户选择

## 数据结构

preference_entry:
  - task_pattern: 任务类型特征
  - suggested_model: 系统建议的模型
  - user_choice: 用户实际选择
  - frequency: 出现次数
  - last_used: 最后使用时间

## 学习规则

1. 正向学习：
   - 用户接受建议 → 该模式权重+1
   - 用户拒绝建议 → 记录用户选择的模型

2. 偏好强化：
   - 同一模式出现3次以上 → 自动应用，无需确认
   - 置信度>90%且用户连续接受 → 跳过确认

3. 遗忘机制：
   - 7天未使用的偏好降级
   - 30天未使用清除记录

## 示例场景

场景1：用户多次处理Python代码
- 输入：Python相关问题
- 系统建议：k2p5 + thinking on
- 用户连续3次接受
- 结果：后续Python问题直接切换，无需确认

场景2：用户偏爱用kimi看文档
- 输入：长文档分析
- 系统建议：kimi
- 用户多次接受
- 结果：文档类任务自动用kimi，跳过确认
