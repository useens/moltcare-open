# k2p5智能难度分级配置
# 第三阶段：自动评估任务难度

## 难度等级定义

### L1 简单 (off)
关键词：
- 语法、报错、怎么写、示例、修复
- 单行代码、简单函数、基础概念
代码特征：
- 代码行数 < 10行
- 单文件修改
- 常见语言（Python/JS）

### L2 中等 (concise)
关键词：
- 函数、模块、实现、接口、调试
- 测试、优化、重构、设计模式
代码特征：
- 代码行数 10-50行
- 2-3个文件关联
- 需要理解上下文

### L3 困难 (on)
关键词：
- 架构、设计、策略、复杂算法
- 分布式、并发、性能、微服务
- 多系统、集成、数据流
代码特征：
- 代码行数 50-200行
- 跨模块/服务设计
- 技术选型决策

### L4 极难 (stream)
关键词：
- 从零设计、核心架构、难点
- 瓶颈、大规模、高可用、容灾
- 疑难bug、深度优化、系统重构
代码特征：
- 代码行数 > 200行或整系统
- 多技术栈整合
- 性能/安全关键路径

## 辅助判断规则

长度权重：
- 消息 > 500字 → +1级
- 消息 > 1000字 → +2级
- 代码块 > 100行 → +1级
- 多文件引用 → +1级

上下文权重：
- 提到"生产环境" → +1级
- 提到"紧急/线上问题" → +1级
- 提到"架构评审/方案" → +1级

## 降级规则
- 明确说"简单问题" → -1级
- 明确说"快速看一下" → 最低L1
