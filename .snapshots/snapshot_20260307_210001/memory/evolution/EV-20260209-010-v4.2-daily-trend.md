## 📋 v4.2 配置

### AI情报收集（每日07:00）

| 维度 | 设置 |
|------|------|
| **监控源** | GitHub + HN热门 + GitHub趋势 |
| **Token预算** | ~15,000（动态） |
| **有趋势时** | 15-20k tokens |
| **无重大发现** | ≤1k tokens |
| **思考级别** | low |

**监控范围**：
- ✅ GitHub OpenClaw组织（安全/版本）
- ✅ HN热门AI/Agent话题（Top 10）
- ✅ GitHub趋势（AI Agent类别，Top 5）
- ❌ arXiv论文（更新慢，移除）
- ❌ 技术博客（分散，移除）

**输出格式**：
```
## AI情报 - MM-DD
- 🔴 安全: [如有]
- 🆕 版本: [如有]
- 🔥 趋势: [3-5个新兴项目]
- 📌 判断: [1句话趋势总结]
```
