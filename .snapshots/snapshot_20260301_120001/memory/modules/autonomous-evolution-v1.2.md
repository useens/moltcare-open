## 效果评估指标与反馈闭环

| 指标 | 目标 | 追踪方式 | 调整策略 |
|------|------|---------|----------|
| 重复发现率 | <10% | 对比历史档案 | >20% → 加强记忆检索深度 |
| 用户采纳率 | >30% | 追踪后续对话 | <20% → 降低预测激进程度 |
| 搁置完成率 | >50% | 检查reminders | <30% → 延长提醒间隔 |
| Token效率 | 持续提升 | 每次执行消耗 | 连续3次高消耗 → 简化流程 |
| 预测准确率 | >40% | accuracy.json | <30% → 提高预测阈值 |

### 反馈闭环机制

**每周自我评估**（周日 23:50）：
```
1. 统计本周指标
   - 发现/安装/跳过比例
   - 预测命中次数
   - Token消耗趋势

2. 策略调整决策
   IF 重复发现率 > 20%:
      → 增加交叉验证深度
   
   IF 用户采纳率 < 20%:
      → 提高预测阈值（3次→5次）
      → 减少激进探索
   
   IF Token消耗连续3天 > 100K:
      → 延长检查间隔（4h→6h）
      → 简化轻量检查流程
   
   IF 预测准确率 < 30%:
      → 调整关键词匹配规则
      → 延长观察窗口（7天→14天）

3. 更新 evolution-strategy.json
```

**动态调整参数**:
- `check_interval`: 4h（可调整 2h-8h）
- `prediction_threshold`: 3次（可调整 2-5次）
- `exploration_depth`: medium（可调整 low/high）

## 新增：目标预测机制

### 预测逻辑

**数据来源**:
- `memory/evolution/meta/user-patterns.json` - 用户高频关键词
- `memory/summary/recent-conversations.md` - 近期对话主题
- `memory/tags/user-instructions.md` - 历史指令模式

**预测触发条件**:
```
关键词出现 >= 3次 且 最近7天内提及
→ 触发相关技能探索

例：
- "清理/优化" x5 → 探索系统清理/优化技能
- "token/成本" x5 → 探索成本监控/优化技能
- "Moltbook" x3 → 探索社区工具技能
- "安全/审计" x3 → 探索安全工具技能
```

**执行策略**:
1. 轻量检查阶段分析用户模式
2. 如检测到高频未满足需求 → 标记"预测探索"
3. 下次全量检查时优先探索相关类别
4. 发现后呈现给用户，记录采纳/忽略

### 预测准确率追踪

`memory/evolution/meta/prediction-accuracy.json`:
```json

  ],

  "threshold_adjust": "动态调整触发阈值"
}
```
