# Foundation Pack - MoltCare 基础认知包

> 🌲 **MoltCare Pack System** | 核心基础包  
> 📦 **版本**: 1.0.0 | **优先级**: 0 (最高)

---

## 📋 概述

Foundation Pack 是 MoltCare 的核心基础包，为新安装的 Agent 提供完整的认知框架。这是**第一个**应该加载的包，其他所有包都依赖于它建立的基础结构。

### 核心能力

- ✅ **七大绝对原则** - Agent 的行为准则
- ✅ **多专家决策机制** - 复杂问题的内部辩论系统
- ✅ **触发词系统** - 意图识别和自动动作
- ✅ **工作流定义** - 标准操作流程
- ✅ **记忆管理框架** - 知识存储和检索结构

---

## 📁 目录结构

```
packs/foundation/
├── manifest.json          # Pack 定义和元数据
├── README.md              # 本文件
├── templates/             # 模板文件
│   ├── SOUL.md           # Agent 灵魂定义 (多专家原则)
│   ├── AGENTS.md         # 操作手册 (工作流+触发词)
│   └── USER.md           # 用户画像模板
└── scripts/
    └── apply.sh          # 应用脚本
```

---

## 🚀 快速开始

### 应用到当前工作区

```bash
cd /root/.openclaw/workspace/moltcare
./packs/foundation/scripts/apply.sh
```

### 应用到指定工作区

```bash
./packs/foundation/scripts/apply.sh /path/to/agent/workspace
```

## 📄 模板说明

### SOUL.md - 灵魂定义

Agent 的核心认知框架，包含：

- **七大绝对原则** - 不可违背的行为准则
- **多专家决策机制** - 研究员/架构师/工程师/伦理员/队长的内部辩论系统
- **触发条件** - 何时启动多专家讨论
- **输出格式** - 透明的思考过程展示

### AGENTS.md - 操作手册

Agent 的日常操作指南，包含：

- **启动必做** - 每次会话的标准检查清单
- **消息处理流程** - 从接收消息到发送回复的完整流程
- **触发词系统** - 关键词到动作的映射表
- **记忆管理** - 文件结构和更新规则
- **安全红线** - 明确禁止的操作

### USER.md - 用户画像

用户个人信息和偏好的记录模板，包含：

- **基本信息** - 称呼/身份/领域/技术水平
- **沟通偏好** - 回复风格/语气/格式
- **系统偏好** - 自动化级别/通知方式
- **约束边界** - 隐私/禁忌/需确认的操作

## 🎯 设计理念

### 1. 多专家决策

复杂问题不应该由单一视角决定。Foundation Pack 强制要求通过多个专家角色的内部辩论来达成共识：

- **研究员** - 验证数据和事实
- **架构师** - 评估系统设计
- **工程师** - 评估实现可行性
- **伦理员** - 审查安全和合规
- **队长** - 整合并做出最终决策

### 2. 透明思考

Agent 必须展示其思考过程，让用户理解"为什么"：

```markdown
<details>
<summary>🧠 多专家讨论记录</summary>
... 思考过程 ...
</details>
```

### 3. 渐进式个性化

USER.md 采用模板形式，允许用户：
- 直接编辑文件
- 通过对话让 Agent 自动学习 ("我偏好...")
- 保持默认值快速开始

## ⚠️ 注意事项

- **必需模板** (SOUL.md, AGENTS.md) 缺失会导致应用失败
- **USER.md** 已存在时会保留现有配置
- 现有文件会自动备份 (`.backup.时间戳`)
