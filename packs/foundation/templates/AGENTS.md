## 🎯 触发词系统

触发词是Agent识别用户意图的关键，通过关键词匹配自动触发动作。

### 核心触发词（高频使用）

| 触发词 | 动作 | 说明 | Signal |
|--------|------|------|--------|
| **"多专家讨论："** | 强制Multi-Agent | 最高优先级，强制启动 | 10 |
| **"记住这个"** | smart_ingest | 记录到学习债务 | 8 |
| **"这很重要"** | smart_ingest + promote | 高优先级标记 | 9 |
| **"别忘记"** | smart_ingest | 创建待办任务 | 7 |
| **"我偏好" / "我更喜欢"** | write_preference | 记录用户偏好 | 6 |
| **"提醒我..."** | create_reminder | 解析定时任务 | 7 |
| **"不要..." / "禁止"** | add_constraint | 记录约束条件 | 8 |

### 次要触发词（按需）

| 触发词 | 动作 | Signal |
|--------|------|--------|
| "学习这个" | smart_ingest | 8 |
| "研究一下" | smart_ingest | 7 |
| "搞不懂" | smart_ingest | 6 |
| "为什么" | smart_ingest | 5（复杂问题） |
| "设计" / "架构" | Multi-Agent | 触发条件已满足 |
| "对比" / "比较" | Multi-Agent | 需要多视角 |
| "优化" / "改进" | Multi-Agent | 涉及权衡分析 |
| "安全" / "风险评估" | Multi-Agent | 需要伦理审查 |

### 触发词优先级

```
最高: "多专家讨论："（强制Multi-Agent）
  ↓
高: "这很重要", "记住这个"
  ↓
中: "提醒我", "别忘记", "我偏好"
  ↓
低: "学习", "研究", "为什么"
```

## 🤖 Multi-Agent 执行细则

### 何时触发？

| 条件 | 动作 |
|------|------|
| 消息以"多专家讨论："开头 | **强制触发** |
| 学习债务Signal≥8 | 自动触发 |
| 关键词: 设计/架构/优化/安全/评估/对比/策略 | 自动触发 |
| 涉及多个系统组件 | 建议触发 |
| 存在明显权衡取舍 | 建议触发 |
| 系统问题数>5 | 自动触发 |

### 执行步骤

1. **识别问题类型** → 确定需要哪些专家
2. **并行思考** → 各专家独立分析
3. **冲突解决** → 队长权衡各观点
4. **方案形成** → 综合为可执行计划
5. **透明输出** → 展示思考过程+结论

### 专家调用规则

```
技术问题: 研究员 + 架构师 + 工程师
设计问题: 架构师 + 工程师 + 伦理员
策略问题: 研究员 + 架构师 + 队长
安全问题: 全员参与（强制）
```

## 🎯 定时 vs 即时任务

| 使用场景 | 推荐方式 | 示例 |
|----------|----------|------|
| 需要对话上下文 | Heartbeat | 基于最近消息判断 |
