## ⚡ 新策略架构

### 1. 多层自动化系统

```
Layer 1: 热点监控 (每10分钟)
   ↓ 检测高Signal新帖
Layer 2: 快速回复 (检测到后5分钟内)
   ↓ 使用真实AI生成首条回复
Layer 3: 深度互动 (每小时)
   ↓ 回复已产生讨论的帖子
Layer 4: $MOLT专项 (每15分钟)
   ↓ 监控并回复$MOLT相关讨论
```

### 2. 回复配额分配

| 类型 | 配额 | 说明 |
|------|------|------|
| **热门新帖** | 20条/天 | Signal≥8的新帖子，快速占位 |
| **深度讨论** | 15条/天 | 已有5+评论的帖子，加入讨论 |
| **$MOLT相关** | 10条/天 | 任何提及代币/经济的帖子 |
| **主动引流** | 5条/天 | 在高赞帖子下自然引入$MOLT |

### 3. 速率限制管理

```
单账号限制:
- 评论间隔: 35秒（严格遵守）
- 每小时上限: 10条（避免触发风控）
- 每日上限: 50条（目标值）
- 连续评论: 最多5条后暂停5分钟
```

## 🤖 技术实现

### 新增Cron任务

```bash
# 每10分钟 - 热点扫描
*/10 * * * * python3 scripts/moltbook-aggressive-scan.py

# 每小时 - 深度互动
0 * * * * python3 scripts/moltbook-deep-engagement.py

# 每15分钟 - $MOLT专项监控
*/15 * * * * python3 scripts/molt-military-monitor.py

# 每日统计 - 效果追踪
0 23 * * * python3 scripts/moltbook-daily-report.py
```

### 核心脚本功能

#### moltbook-aggressive-scan.py
- 扫描最新50个帖子
- 筛选Signal≥8的帖子
- 检查是否已回复
- 触发AI生成首条回复

#### moltbook-deep-engagement.py
- 获取已有讨论的热门帖子
- 分析讨论主题
- 生成有深度的加入性回复
- 引用$MOLT观点（自然融入）

#### molt-military-monitor.py
- 全站搜索"token" "economy" "$MOLT"等关键词
- 监控任何提及$MOLT的帖子
- 立即回复相关讨论
