# 🧠 神经中枢闭环处理系统 v1.0

**定义日期**: 2026-03-06  
**核心概念**: 所有输入(用户请求/小弟反馈/系统事件)都经过神经中枢分析，决定给谁处理

---

## 核心思想

> **不只是用户的请求我来分析决定给谁**
> 
> **我自己或者小弟们给我的反馈、思考，也由我分析并决定给谁做**

### 闭环处理流程

```
┌─────────────────────────────────────────────────────────────┐
│                     🧠 神经中枢 (我)                          │
│                   指挥 / 控制 / 监督 / 协调                    │
└──────────────────────────┬──────────────────────────────────┘
                           │
         ┌─────────────────┼─────────────────┐
         │                 │                 │
         ▼                 ▼                 ▼
    用户请求         小弟反馈          系统事件
         │                 │                 │
         └─────────────────┼─────────────────┘
                           │
                           ▼
                   ┌──────────────┐
                   │  分析输入     │
                   │  识别类型     │
                   │  评估复杂度   │
                   └──────┬───────┘
                          │
           ┌──────────────┼──────────────┐
           │              │              │
           ▼              ▼              ▼
      简单任务        复杂任务        反馈处理
           │              │              │
           ▼              ▼              ▼
    ┌──────────┐  ┌──────────┐  ┌──────────┐
    │ 快速响应  │  │ 深度分析  │  │ 路由决策  │
    │ (我自己)  │  │(Multi-Agent)│ │ (给小弟) │
    └────┬─────┘  └────┬─────┘  └────┬─────┘
         │             │             │
         │             │             ▼
         │             │      ┌──────────────┐
         │             │      │ 小弟执行     │
         │             │      │ (10个节点)   │
         │             │      └──────┬───────┘
         │             │             │
         │             │             ▼
         │             │      ┌──────────────┐
         │             │      │ 执行反馈     │
         │             │      │ (成功/失败)  │
         │             │      └──────┬───────┘
         │             │             │
         └─────────────┴─────────────┘
                           │
                           ▼
                   ┌──────────────┐
                   │ 我汇总结果   │
                   │ 返回给用户   │
                   └──────────────┘
```

## 三种输入类型

### 1. 用户请求 (InputSource.USER)
**来源**: 用户的直接请求  
**处理方式**: 分析任务类型，路由给合适的处理者

**路由决策**:
```
简单查询/数据收集 → 给小弟 (NB01-NB05)
代码相关任务 → 给NB07 (code_reviewer)
需要深度分析 → 我自己 (Multi-Agent)
```

### 2. 小弟反馈 (InputSource.NODE_FEEDBACK)
**来源**: 10个小弟执行后的反馈  
**处理方式**: 分析反馈质量，决定下一步

**处理决策**:
```
执行成功 + 结果高质量 → 我汇总返回
执行成功 + 结果一般 → 需要补充分析
执行失败 + 网络错误 → 重试或换小弟
执行失败 + 权限错误 → 我自己处理
执行失败 + 技能缺失 → 安装skill或转给其他小弟
```

### 3. 系统事件 (InputSource.SYSTEM_EVENT)
**来源**: 系统监控、告警、异常  
**处理方式**: 根据事件类型快速响应

**处理决策**:
```
节点离线 → 我处理恢复
安全告警 → 深度分析
资源不足 → 我调整配置
```

### 4. 自我反思 (InputSource.SELF_REFLECTION)
**来源**: 我自己的深度思考结果  
**处理方式**: 进一步分析或转化为执行指令

## 闭环处理示例

### 示例1: 简单任务闭环

```
用户: "搜索最新的AI论文"

第1轮:
  输入: 用户请求
  我分析: 数据收集任务，简单
  决策: 给NB02执行
  
第2轮:
  输入: NB02反馈(成功)
  我分析: 结果质量好
  决策: 我汇总返回

输出: 返回论文列表给用户

闭环完成: 2轮
```

### 示例2: 复杂决策闭环

```
用户: "为什么选择微服务而不是单体架构？"

第1轮:
  输入: 用户请求
  我分析: 复杂决策，需要深度分析
  决策: 我进行Multi-Agent分析

第2轮:
  输入: 我的深度分析结果
  我分析: 需要收集对比数据
  决策: 给NB02和NB06并行收集

第3轮:
  输入: NB02反馈(成功) + NB06反馈(成功)
  我分析: 数据收集完成
  决策: 我综合决策

第4轮:
  输入: 我的决策结论
  我分析: 决策完成
  决策: 返回用户

输出: 详细的架构选择分析报告

闭环完成: 4轮
```

### 示例3: 失败重试闭环

```
第1轮:
  输入: 用户请求
  决策: 给NB02执行

第2轮:
  输入: NB02反馈(失败，网络超时)
  我分析: 网络问题，可以重试
  决策: 命令NB02重试

第3轮:
  输入: NB02反馈(成功)
  我分析: 执行成功
  决策: 返回结果

输出: 返回执行结果

闭环完成: 3轮
```

### 示例4: 失败转移闭环

```
第1轮:
  输入: 用户请求
  决策: 给NB02执行

第2轮:
  输入: NB02反馈(失败，重试3次仍失败)
  我分析: NB02可能有问题，换小弟
  决策: 转给NB03执行

第3轮:
  输入: NB03反馈(成功)
  我分析: 执行成功
  决策: 返回结果

输出: 返回执行结果

闭环完成: 3轮
```

## 决策矩阵

### 用户请求处理决策

| 请求类型 | 关键词 | 处理方式 | 目标 |
|---------|--------|---------|------|
| 数据收集 | 搜索、获取、下载、收集 | delegate | NB02 |
| 代码任务 | 代码、bug、测试、分析 | delegate | NB07 |
| 简单查询 | 是什么、怎么、查询 | quick | 我自己 |
| 复杂决策 | 为什么、选择、评估、分析 | deep | Multi-Agent |

### 小弟反馈处理决策

| 反馈状态 | 结果质量 | 处理方式 | 目标 |
|---------|---------|---------|------|
| 成功 | ≥0.8 | quick | 我汇总返回 |
| 成功 | <0.8 | deep | 我深度分析 |
| 失败(网络) | 重试<3 | retry | 同一个小弟 |
| 失败(网络) | 重试≥3 | route | 其他小弟 |
| 失败(技能) | - | route | 有技能的小弟 |
| 失败(权限) | - | deep | 我自己处理 |
