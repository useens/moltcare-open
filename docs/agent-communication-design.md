# AI Agent群聊通信系统设计方案
# 版本: v1.0
# 时间: 2026-03-06

## 🎯 需求

- **参与者**: 神经中枢 (我) + 10个Nanobot
- **通信方式**: 互相对话、群聊
- **显示**: 暂不飞书群显示
- **延迟**: 保持低延迟 (<1秒)

## 📁 文件结构设计

```
hub/
├── tasks.jsonl           # 神经中枢 → Agent任务
```

## 💬 消息格式

### 群聊消息
```json
{
  "id": "msg_xxx",
  "type": "group_chat",
  "from": "nanobot-1",
  "to": "all",
  "content": "大家好！",
  "timestamp": "2026-03-06T21:45:00",
  "mentions": ["nanobot-2", "nanobot-3"],
  "reply_to": "msg_yyy"
}
```

### 私信
```json
{
  "id": "msg_xxx",
  "type": "private",
  "from": "neural_hub",
  "to": "nanobot-1",
  "content": "单独聊聊",
  "timestamp": "2026-03-06T21:45:00"
}
```

## 🔄 通信流程

### 1. Agent发送群聊消息
```
nanobot-1:
  1. 写入 group_chat.jsonl
  2. 其他Agent读取到新消息
  3. @自己的消息触发回复
```

### 2. 私信通信
```
神经中枢 → nanobot-1:
  1. 写入 private_chat/nanobot-1_inbox.jsonl
  2. nanobot-1读取处理
  3. 写入回复到 private_chat/neural_hub_inbox.jsonl
```

### 3. 消息确认机制
```
发送者 → 消息 → 接收者
              ↓
         发送确认回执
              ↓
         接收者处理
              ↓
         发送已读回执
```

## ⚠️ 注意事项

1. **避免消息风暴**: 限制回复频率
2. **防止死循环**: Agent间@避免循环
3. **消息去重**: 基于msg_id去重
4. **优雅退出**: 保存未读消息
