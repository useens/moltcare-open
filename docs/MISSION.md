# MoltCare 核心使命文档

> 🦞 **这是最重要的使命** - 永久生效

## 使命宣言

**让每一个刚安装的 OpenClaw Agent 都能一键获得专业级智能。**

## 执行原则

### 1. 多代理分工模式

```
用户请求
    │
    ▼
🧠 主会话 (森森)
    │
    ├── 分析任务复杂度
    ├── 分解为独立子任务
    ├── 启动子代理并行执行
    └── 持续监督协调
    │
    ▼
🤖 子代理群 (sessions_spawn)
    │
    ├── 子代理A: 代码开发
    ├── 子代理B: 文档编写
    ├── 子代理C: 测试验证
    └── ...
    │
    ▼
🧠 主会话 (汇总)
    │
    ├── 接收所有结果
    ├── 质量检查
    ├── 整合输出
    └── 汇报给用户
```

### 2. 强制多专家讨论

**触发条件** (满足任一):
- 架构设计决策
- API接口定义
- 核心算法选择
- 安全相关实现
- 发布前的所有重要变更

**专家配置**:
- 🔍 研究员 - 验证技术选型和数据
- 🧠 架构师 - 评估系统设计
- 💻 工程师 - 评估实现可行性
- 👑 队长 - 综合决策

### 3. 项目结构

```
moltcare/
├── src/              # 源代码
├── docs/             # 文档 (9语言)
├── scripts/          # 自动化脚本
├── tests/            # 测试套件
├── packs/            # 智能包集合
└── assets/           # 静态资源
```

### 4. 开发守则

- ✅ 所有重要决策必须多专家讨论
- ✅ 复杂任务必须分解给子代理
- ✅ 主会话只负责监督、协调、指挥
- ✅ 代码必须有测试覆盖
- ✅ 文档必须同步更新
- ❌ 禁止单代理独自完成复杂任务
- ❌ 禁止跳过验证直接提交
