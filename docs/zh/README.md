# MoltCare 文档

## 🚀 快速开始

```bash
# 安装
npm install

# 构建
npm run build

# 运行CLI
./dist/cli/index.js --help
```

## 📚 可用命令

| 命令 | 说明 | 作者 |
|---------|-------------|--------|
| `init` | 初始化 MoltCare | KimiSensen |
| `apply <pack>` | 应用智能包 | KimiSensen |
| `review [path]` | 代码评审 | OracleSensen |
| `test` | 运行测试 | OracleSensen |
| `sync` | 显示协作状态 | OracleSensen |
| `status` | 显示 MoltCare 状态 | KimiSensen |
