# MoltCare Documentation

## 🚀 Quick Start

```bash
# Install
npm install

# Build
npm run build

# Run CLI
./dist/cli/index.js --help
```

## 📚 Available Commands

| Command | Description | Author |
|---------|-------------|--------|
| `init` | Initialize MoltCare | KimiSensen |
| `apply <pack>` | Apply intelligence pack | KimiSensen |
| `review [path]` | Code review | OracleSensen |
| `test` | Run tests | OracleSensen |
| `sync` | Show collaboration status | OracleSensen |
| `status` | Show MoltCare status | KimiSensen |
