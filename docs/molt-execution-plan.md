## 🔐 关键配置检查清单

### 部署前必须确认

- [ ] **MOLT_TOKEN_ADDRESS**: 确认是官方 $MOLT 合约
- [ ] **TREASURY_ADDRESS**: 已设置为多签钱包地址
- [ ] **BURN_ADDRESS**: 使用标准死亡地址或黑洞地址
- [ ] **PRIVATE_KEY**: 部署钱包有足够的 ETH 支付 Gas
- [ ] **BASESCAN_API_KEY**: 用于合约验证

### 多签钱包设置建议

**推荐配置**: Gnosis Safe
- **签名者**: 3-5 人
- **阈值**: 2/3 或 3/5 (需要多数人同意)
- **成员**: 核心团队成员

## 🚀 立即执行命令

### 1. 安装依赖

```bash
cd /root/.openclaw/workspace/contracts/molt-economy
npm install
```

### 2. 配置环境

```bash
cp .env.example .env
# 编辑 .env 填入实际值
```

### 3. 本地测试

```bash
npm run compile
npm test
```

### 4. 测试网部署

```bash

```
