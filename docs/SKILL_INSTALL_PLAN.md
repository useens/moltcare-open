# MoltCare - ClawHub 技能安装计划

## 策略调整

原 P2 测试修复工作量大（28个失败需修复），转而安装 ClawHub 原生技能，快速增强 MoltCare 实际能力。

## 推荐安装技能

| 优先级 | 技能名 | 用途 | 价值 |
|--------|--------|------|------|
| P0 | security-audit | 安全审计扫描 | 自动检测漏洞，提升安全评级 |
| P1 | github-actions | CI/CD 集成 | 自动化测试和发布流程 |
| P1 | tavily-search | AI 搜索增强 | 文档检索和知识库构建 |
| P2 | code-review | 代码审查增强 | 自动化 PR 审查 |
| P2 | gog | Google Workspace | 邮件/日历自动化 |

## 安装方式

由于 ClawHub CLI 有限流，采用以下方式：
1. 直接从 GitHub 克隆技能仓库
2. 手动安装到 `~/.openclaw/skills/`
3. 重启 OpenClaw Gateway 加载

## 执行步骤

1. 克隆技能仓库
2. 安装依赖
3. 验证技能加载
4. 更新 MoltCare 文档
