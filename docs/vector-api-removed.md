# 向量搜索API移除说明

**日期**: 2026-02-13  
**决策**: 彻底删除向量搜索API设置需求

---

## 决策原因

向量搜索API (OpenAI/Google/Voyage) **不再需要**。

**原因**:
- 文件系统替代方案已正常工作
- 分层记忆架构 (daily/curated) 足够高效
- 关键词搜索 + 文件系统索引 满足当前需求
- 减少外部API依赖，降低Token消耗

---

## 当前方案

**替代方案**: 文件系统 + 分层记忆

```
memory/
├── daily/           # 每日原始记录
├── curated/         # 精选长期记忆
├── modules/         # 核心档案
└── knowledge-graph.md  # 知识图谱
```

**优势**:
- ✅ 零API成本
- ✅ 本地运行，无网络依赖
- ✅ 完全可控
- ✅ 性能足够

---

## 已移除内容

- ❌ OpenAI API key配置需求
- ❌ Google embedding API配置需求  
- ❌ Voyage API配置需求
- ❌ 向量数据库维护需求

---

## 保留能力

- ✅ 语义检索 (基于关键词+文件系统)
- ✅ 记忆搜索 (基于路径索引)
- ✅ 知识图谱 (基于手动整理)
- ✅ 学习债务追踪

---

**结论**: 文件系统替代方案已充分满足需求，无需向量搜索API。
