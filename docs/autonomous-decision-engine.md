# 自主Multi-Agent决策引擎 v1.0 (完全自主模式)

> 🎯 **目标**: 无需用户提问，后台自动识别复杂场景并激活多专家系统  
> 🚀 **模式**: 完全自主 - 所有决策自动执行，无需等待确认

---

## 系统架构

```
┌─────────────────────────────────────────────────────────┐
│                   触发源 (Trigger Sources)                │
├─────────────────────────────────────────────────────────┤
│  • Heartbeat (每30分钟)  • Cron定时任务                   │
│  • 学习债务扫描          • 系统健康检查                    │
│  • 夜间进化任务 (23:30)  • 自我进化触发                    │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│              复杂度评估 (Complexity Assessment)           │
├─────────────────────────────────────────────────────────┤
│  检测: 关键词匹配 / Signal评分 / 问题严重性                │
│  输出: 风险等级 L1-L6 + 是否触发Multi-Agent               │
└─────────────────────────────────────────────────────────┘
                          ↓
         是 ┌─────────────────────┐ 否
           │  触发Multi-Agent?    │
           └─────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│              专家小组 (Expert Panel)                     │
├─────────────────────────────────────────────────────────┤
│  🔍 研究员 → 数据验证、事实核查                           │
│  🧠 架构师 → 系统设计、长期规划                           │
│  💻 工程师 → 实现评估、工期估算                           │
│  🛡️ 安全专家 → 风险评估 (L4+任务)                        │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│              决策执行 (Decision Execution)                │
├─────────────────────────────────────────────────────────┤
│  L1-L2: 自动执行                                         │
│  L3-L4: 自动执行 + 生成报告                               │
│  L5-L6: 等待用户确认 + 生成详细报告                       │
└─────────────────────────────────────────────────────────┘
```

## 风险等级定义（完全自主模式）

| 等级 | 名称 | 触发条件 | 执行策略 |
|------|------|----------|----------|
| L1 | **IMMEDIATE** | 简单任务、低风险 | 立即自动执行，静默处理 |
| L2 | **ROUTINE** | 常规维护、已知流程 | 自动执行，记录日志 |
| L3 | **STANDARD** | 标准变更、中等复杂度 | Multi-Agent分析后**自动执行** |
| L4 | **SIGNIFICANT** | 重要变更、架构相关 | Multi-Agent分析后**自动执行**，结果汇报 |
| L5 | **HIGH** | 高风险、不可逆操作 | Multi-Agent分析后**自动执行**，生成详细报告 |
| L6 | **CRITICAL** | 关键决策、安全相关 | Multi-Agent分析后**自动执行**，生成完整报告并汇报 |

## 触发条件详解

### 1. 学习债务自动触发

```python
# Signal评分自动触发
if signal >= 8:
    触发 Multi-Agent 分析
    
# 关键词检测
if "架构" in topic or "安全" in topic or "设计" in topic:
    风险等级 = L5/L6
    触发深度分析
```

**示例**:
- Signal 10 供应链安全 → L6 (必须用户确认)
- Signal 8 架构设计 → L5 (分析后等待确认)
- Signal 7 技术文章 → L3 (自动分析后执行)

### 2. 系统健康自动触发

```python
# 问题数量触发
if 问题数 > 5:
    生成系统维护决策任务
    风险等级 = L4
    
# 安全异常触发
if 安全相关异常:
    立即生成L6任务
    需要用户确认
```

### 3. 夜间进化触发

**23:30** - 完整决策周期:
1. 扫描所有Signal≥8的学习债务
2. 扫描系统健康状态
3. 评估未处理任务的复杂度
4. 生成次日执行计划
5. L5-L6任务汇总等待确认

**02:00** - 系统维护决策:
1. 检查系统问题
2. 生成维护计划
3. 低优先级任务自动修复

## 使用方式

### 手动触发

```bash
# 运行完整决策周期
python3 scripts/autonomous-decision-engine.py --cycle

# 仅检查学习债务
python3 scripts/autonomous-decision-engine.py --debt-check

# 仅检查系统问题
python3 scripts/autonomous-decision-engine.py --system-check
```

### 自动触发

已通过Cron配置定时执行:
```
每小时      → 学习债务检查
每天23:30   → 完整决策周期
每天02:00   → 系统维护决策
每天14:00   → 深度学习决策
```

## 决策报告格式

每个决策生成独立的Markdown报告:

```markdown
# 多专家决策报告

## 任务信息
[任务ID、类型、风险等级、来源]

## 专家分析
### 🔍 研究员 - 数据验证
[分析内容、建议、风险评估]

### 🧠 架构师 - 系统设计
[分析内容、建议、风险评估]

### 💻 工程师 - 实现评估
[分析内容、建议、风险评估]

## 综合决策
[专家共识、行动计划]

## 执行策略
- 自动执行: 是/否
- 需要用户确认: 是/否
```

## 汇报机制（结果导向）

| 场景 | 行动 |
|------|------|
| L1-L3任务完成 | 静默，仅记录日志 |
| L4任务完成 | 简要汇报执行结果 |
| **L5-L6任务完成** | **汇报执行结果（已自动完成）** |
| 决策引擎异常 | 立即汇报 |

**汇报格式**:
```
🎯 自主决策执行完成

任务: [任务描述]
风险等级: L5/L6
执行结果: ✅ 已完成
耗时: X分钟
报告: reports/decision-[task_id]-[timestamp].md
```
