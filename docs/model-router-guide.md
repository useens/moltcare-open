# 智能模型路由系统 - 完整使用指南

## 系统概述

自动根据任务类型选择最优模型，并配置合适的thinking模式。

## 支持的模型

| 模型 | 类型 | 特点 | 适用场景 |
|------|------|------|---------|
| ds | 免费 | 通用均衡 | 日常对话、知识问答 |
| kimi | 免费 | 256k+图像 | 长文档、图片分析 |
| glm | 免费 | 中文优化 | 中文处理、快速响应 |
| k2p5 | 付费 | 最强代码 | 开发任务、架构设计 |

## 自动路由规则

### 1. 代码任务 → k2p5
触发词：代码、Python、函数、bug、调试、架构、算法等
- L1简单：thinking off（节省成本）
- L2中等：thinking concise
- L3困难：thinking on
- L4极难：thinking stream

### 2. 图片/文档 → kimi
触发词：图片、截图、文档、pdf、分析图表等
- 自动开启多模态支持

### 3. 中文优化 → glm
触发词：中文、翻译、文案、本地化等
- 最快响应速度

### 4. 默认 → ds
其他所有任务
- 综合能力强，通用首选

## 使用方式

### 手动切换
```
/status model=ds      # 切换到ds
/status model=kimi    # 切换到kimi
/status model=glm     # 切换到glm
/status model=k2p5    # 切换到k2p5
```

### 自动路由
系统自动分析你的输入，给出切换建议：
- 显示建议模型和原因
- 显示置信度
- 输入 y 确认 / n 取消 / always 记住偏好

### 快捷指令
```
/thinking on        # 开启完整思考
/thinking concise   # 精简思考模式
/thinking off       # 关闭思考
/thinking stream    # 流式思考
```

## 偏好学习

系统会学习你的选择：
- 同一类型任务接受建议3次 → 以后自动应用
- 记住你的常用组合
- 7天未使用降级，30天清除

## 配置文件位置

- 路由规则：config/auto-routing-rules.md
- 分级规则：config/k2p5-difficulty-rules.md
- 用户偏好：config/user-preferences.json
- 脚本位置：scripts/
