## 实施内容

### Layer 1: 精确触发 (Signal +2)

保留原有精确触发词：

| 触发词 | 动作 | 反馈 |
|--------|------|------|
| "多专家讨论：" | 启动多专家模式 | [🧠] |
| "这很重要" | 高优先级记忆 | [⭐] |
| "记住这个" | 添加到学习债务 | [💾] |
| "我偏好" | 记录用户偏好 | [👤] |
| "不要"/"禁止" | 添加约束 | [🚫] |

### Layer 2: 语义触发 (Signal +1) - MVP

新增自然语言触发规则：

| 触发类型 | 关键词示例 | Signal | 反馈 |
|----------|------------|--------|------|
| 关键信息 | "关键是..." / "核心在于..." / "重点是..." | +1 | [⭐] |
| 学习债务 | "别忘了..." / "要记住..." / "得留意..." | +1 | [💾] |
| 用户偏好 | "我喜欢..." / "我讨厌..." / "我倾向于..." | +1 | [👤] |
| 约束 | "千万不要..." / "绝对不能..." / "千万别..." | +1 | [🚫] |
| PUA沮丧 | "还不行" / "太慢了" / "不对" / "搞错了" | L1 | [🔥] |

### Layer 3: Agent 主动评估 (自动) - 完整版

**价值判断清单** (7项自检问题):
- [ ] 是否解决了用户反复提到的问题？
- [ ] 是否纠正了之前的错误理解？
- [ ] 是否发现了用户的隐含偏好？
- [ ] 是否是首次出现的模式/习惯？
- [ ] 是否涉及 L4-L5 级别的重要决策？
- [ ] 是否成功突破了技术难点？
- [ ] 是否建立了新的工作模式/流程？

**自动记录规则**:

| 满足条件 | 动作 | 反馈 |
|----------|------|------|
| ≥2 项满足 | 写入 `memory/YYYY-MM-DD.md` | [📝] 已记录今日交互 |
| ≥3 项满足 | 更新 `MEMORY.md` 高信号区 | [⭐] 已更新核心记忆 |
| 涉及偏好/约束 | 更新 `USER.md` | [👤] 已更新偏好 |
| PUA 过程 | 记录到 `learning-debt.md` | [💾] 已记录解决路径 |

**反馈抑制**:
- 同一话题 1 小时内不重复记录
- 连续 3 次自动记录后静默
- 用户说"这不重要"→ 降低敏感度

## 优先级架构

```
┌─────────────────────────────────────────────────────┐
│  Layer 1: 精确触发  (Signal +2)  🔴 最高优先级       │
│  - "这很重要"、"记住这个"、"我偏好"                 │
├─────────────────────────────────────────────────────┤
│  Layer 2: 语义触发  (Signal +1)  🟡 中等优先级       │
│  - "关键是..."、"别忘了..."、"我喜欢..."            │
├─────────────────────────────────────────────────────┤
│  Layer 3: 主动评估  (自动计算)   🟢 最低优先级       │
│  - 任务完成后自检，满足条件自动记录                   │
└─────────────────────────────────────────────────────┘
```

**冲突处理**: 高优先级覆盖低优先级，避免重复记录和反馈。
