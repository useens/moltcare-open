# TOKEN_AUDIT.md - Token 优化审查配置

> ⚙️ **自动执行配置** - 每周审查 Token 使用效率

---

## 执行频率

**每周一次** - 每周一凌晨 3:00 自动执行

---

## 触发方式

### 1. 自动执行 (推荐)
```bash
# 已配置 cron，每周一 03:00 自动执行
0 3 * * 1 cd ~/.openclaw/workspace && echo "检查token优化" >> ~/.openclaw/workspace/.audit-trigger
```

### 2. 手动触发
```
用户: "检查token优化"
Agent: [📊] 执行 Token 优化审查...
```

### 3. 指定周期
```
用户: "检查本周token优化"
用户: "检查本月token优化"
```

---

## 审查内容

| 检查项 | 阈值 | 动作 |
|--------|------|------|
| 重复性 AI 任务 | 同一任务 >3 次/周 | 建议脚本化 |
| 高频查询 | 查询同一数据 >5 次/周 | 建议缓存 |
| 阈值判断用 AI | 简单 if 判断用 AI | 建议规则化 |
| 数据格式化用 AI | 纯转换操作 | 建议脚本化 |
| 缓存命中率 | <60% | 优化缓存策略 |
