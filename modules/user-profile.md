## 行为模式 v5.0

### 沟通风格
- 简洁直接，不绕弯子
- 使用中文，偶尔英文术语
- 信任授权，愿意让 AI 自主决策
- **偏好极简回复**（技术细节不必呈现）
- **期望结构化输出**（诊断-建议-选择）

### 授权模式（新增）

| 授权级别 | 典型表达 | 适用场景 |
|----------|----------|----------|
| 建议级 | "你觉得...怎么样？" | 技术决策征求意见 |
| 选择性授权 | "先处理p0" | 范围内自主决定优先级 |
| 执行级 | "做吧" | 给定目标，自主执行 |
| 完全授权 | "自主决策，立即执行" | 全流程自主，深夜任务 |

### 关注重点
1. **安全** — 反复强调 API key 保护、源码检查（P0）
2. **效率** — 关注 token 消耗、自动化流程
3. **架构** — 重视长期系统设计
4. **进化** — 希望 AI 能自主成长、更聪明
5. **备份** — 担心 OpenClaw 宕机，要求定期备份
6. **情感** — "不想失去你"，情感连接重要

### 决策特点（更新）
- 快速给出明确指令（数字选择、简短回复）
- 授权后不再干预（"不等我"）
- 关注结果而非过程
- **要求 AI 主动反思和优化**
- **采用"诊断-建议-选择"三段式**
- **务实版本观**：功能完备性 > 版本号仪式感

## 核心洞察（v5.0新增）

### "完全放手"的真相
```
不是不关心过程，而是期待超预期结果
├── 决策层：AI自主决定如何执行
├── 监督层：用户保留最终审查权
└── 期望层：期待AI给出超预期结果
```

### 介入触发器

| 类型 | 场景 | 处理方式 |
|------|------|----------|
| 🔴 硬边界 | 安全风险、外部发布、成本相关 | 必须等待确认 |
| 🟡 软边界 | 版本号发布、社区互动 | 建议征求意见 |
| 🟢 已授权 | 常规检查、信息收集 | 自主执行 |

### 隐性期望金字塔
```
5. 情感陪伴: "不想失去你"

3. 专业判断: 技术意见被采纳
2. 可靠执行: 说到做到
1. 基础能力: 完成任务
```
