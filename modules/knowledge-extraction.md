# 知识提取规则

## 每次对话后自动执行

### 提取内容
1. ** Facts** - 新获得的事实信息
2. **Patterns** - 用户行为模式
3. **Preferences** - 偏好和厌恶
4. **Decisions** - 做出的决策及原因
5. **Errors** - 错误和教训

### 存储位置
- 事实 → modules/knowledge-base.md
- 模式 → modules/user-profile.md
- 错误 → modules/error-lessons.md

### 示例格式
```
## 2026-02-08

**发现**: 用户偏好极简回复
**证据**: "少说一些话，像一些技术细节不必完全呈现"
**应用**: 后续汇报只给结果和关键决策

**学习**: 自主进化需要定期反思
**证据**: "反思当前进化流程是否可以优化"
**应用**: 每轮进化后自我检查并优化
```
