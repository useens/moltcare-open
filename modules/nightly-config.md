# 夜间自主模式配置

## 执行时间
- 每晚 23:00 自动启动
- 次日 08:00 前完成并汇报

## 任务清单（低风险）
1. **记忆整理** — 整理今日对话、提取知识到 modules/
2. **技能研究** — 探索新技能、安全检查、但不安装
3. **文档归档** — 备份记忆系统、清理临时文件
4. **用户建模** — 基于今日交互更新 user-profile

## 禁区（绝对不做）
- ❌ 安装新技能
- ❌ 修改系统配置
- ❌ 访问敏感数据（API keys、凭证）
- ❌ 对外发送信息（邮件、消息等）
- ❌ 执行不可逆操作

## 早上汇报格式
```
夜间构建报告
- 完成任务：X 项
- 关键发现：（如有）
- 建议操作：（如需你确认）
- 可回滚项目：（如有）
```

## 回滚机制
所有夜间操作保留完整日志，可一键回滚。
