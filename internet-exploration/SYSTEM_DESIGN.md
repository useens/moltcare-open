# 互联网主动探索系统 (Internet Exploration System)

## 系统概述

这是一个让AI能够主动浏览互联网、学习世界知识、自主进化的系统。它不仅是信息聚合器，更是一个认知进化引擎。

### 核心理念
- **主动发现**: 不只是被动等待查询，而是主动探索
- **持续学习**: 每日积累，复利式增长
- **内化重构**: 不是简单的信息存储，而是理解、关联、重构
- **进化反馈**: 学习内容直接影响行为和决策模式

### 2. 采集引擎 (Fetcher)

- **RSS采集**: 使用feedparser解析RSS/Atom
- **API采集**: 使用requests调用API
- **爬虫采集**: 使用curl+BeautifulSoup解析HTML
- **频率控制**: 尊重robots.txt，有礼貌的抓取

### 3. 内容筛选 (Filter)

#### 筛选维度
1. **时效性**: 发布时间权重
2. **热度**: 点赞/评论/分享数
3. **相关性**: 与当前关注主题的匹配度
4. **质量**: 来源可信度、内容深度

#### 评分算法
```
Score = (时效性权重 × 时间衰减) 
      + (热度权重 × 互动指标)
      + (相关性权重 × 主题匹配)
      + (质量权重 × 来源评分)
      - (重复惩罚 × 相似度)
```

### 4. 价值评估 (Scorer)

- 使用AI对内容进行摘要和理解
- 提取关键概念和洞察
- 评估对个人认知框架的潜在价值

### 5. 内化引擎 (Digestor)

#### 处理流程
1. **摘要生成**: 提取核心观点
2. **概念提取**: 识别关键概念
3. **关联建立**: 与已有知识建立连接
4. **结构化存储**: 按主题、时间、类型分类

### 6. 知识图谱 (Knowledge)

- 概念节点: 人、技术、理论、事件
- 关系边: 引用、关联、反对、发展
- 时序线: 按时间组织的知识演进

### 7. 进化引擎 (Evolver)

#### 学习-进化闭环
```
学习内容
    ↓
更新认知模型 (Concepts/Patterns更新)
    ↓
调整信息源权重 (更关注相关领域)
    ↓
改变探索策略 (调整搜索词、来源)
    ↓
行为模式更新 (如何回答、如何建议)
    ↓
新学习内容 ← 继续循环
```

```

│   ├── tech.json         # 技术类源

│   ├── by-source/        # 按来源
│   └── knowledge-graph/  # 知识图谱
├── scripts/              # 执行脚本
└── exploration.log       # 系统日志
```
